# 晋江编辑端五大模式（开 / 中 / 尾 / 主动 / 关系）

> 目的:把「晋江爆款」拆成 5 个**编辑端可操作、可 lint、可改稿**的模式,让每一章动笔前、动笔后都能对位到 5 条之一,并各自有「必带 / 禁用 / 工艺清单」。
>
> 来源:
> - S0/S1:`reports/jinjiang-r20/research-notes.md`(晋江官方 + 行业共识)
> - S2:`docs/standards/晋江爆款基线.md` 工程 5 维 + `tools/jinjiang_chapter_distance.py` 公式
> - S3 sub-agent 模拟:`reports/jinjiang-r20/sub-agent-cross-pollination-2026-09-04.md`
> - 工艺样板:`docs/standards/文笔范文标准.md` 头 10 章范文
> - 上层:`docs/standards/jinjiang-quality-architecture.md`(四层证据栈)
>
> 适用:每一章动笔前、动笔后。改稿时按 §六 改稿操作表对位。

---

## 0. 三句话

1. 晋江爆款不是单维,是 **5 个模式同章叠加**。每章必须有 ≥ 4 个模式达到 7+;少一个,这一章就不进爆款候选。
2. 5 个模式不是「写得更好看」,是「编辑端可证伪的判断」:每条都有触发条件 + lint + 改稿操作 + 禁用清单。
3. sub-agent 模拟 + 真人盲读只能给「方向感」;每个模式必须在机器端有 `prose_lint` / `review_batch` / `jinjiang_chapter_distance` 三个工具同时校验。

## 1. 五大模式总表

| 编号 | 模式 | 7+ 阈值判据 | 默认配重 |
|---|---|---|---|
| **M1** | 开场钩 | 首段 ≤ 180 字内出现 ≥ 2 个动作动词 + ≥ 1 个阻力词 | E1 |
| **M2** | 中段选择 | POV 角色本章做了一次改变局面的选择 + ≥ 1 个代价 | E2 |
| **M3** | 章尾钩 | 末段停在动作前 / 身份误认 / 未答问题 / 新证据,不是泛化情绪 | E3 |
| **M4** | POV 主动 | POV 角色本章 ≥ 2 个 agency verb(决定 / 改为 / 不再 / 签下 / 主动) | E4 |
| **M5** | 关系后果 | ≥ 1 对人物关系发生可追踪的升降,带 ≥ 1 个具体动作或代价 | E5 |

每章必须满足 M1 + M3 + M4 三条硬门槛。M2 / M5 是软门槛,但缺一即降一档。

## 2. M1 · 开场钩(开篇)

### 2.1 必带

- 首句是**威胁 / 动作 / 矛盾**,不是背景铺陈。
- 首段(≤ 180 字)出现 ≥ 2 个动作动词 + ≥ 1 个阻力词(却 / 但 / 没有 / 拦 / 不 / 别)。
- 第一句或第二句必须有一个 POV 角色做事的具体动作,不是「她站在门前」式状态描写。

### 2.2 禁用

- 「她站在门前,看着窗外的雪」式开场——状态不是钩。
- 「她想到/她记得/她回忆」式开场——回忆不能扛钩。
- 「那年那月」式时间铺陈——晋江读者不知道「那年那月」是谁的。
- 「她很美 / 茶很香 / 天很冷」式形容词开场——形容词是天花板,不是钩子。
- 首段 180 字内出现 ≥ 3 个世界观术语——跨题材读者会弃读。

### 2.3 工艺清单

- 钩子的最小骨架:**谁 + 做什么 + 被什么挡**。三个元素必须在前 180 字内全部出现。
- 阻力词不一定是「被否定」,也可以是「被沉默」(`他不接话`)、「被身体卡住」(`手到胸前三寸,停住了`)、「被名字卡住」(`她没叫`)——任何阻止下一步动作的东西都算。
- 第一段写完后,把首句单独拎出来读:陌生读者只读这一句能不能知道本章要发生什么?不知道 → 重写。
- 范文样例:第 1 回「签了它,你还是林家人;不签,你今晚就从祠堂里抬出去。」(M1 + M4 同句)

## 3. M2 · 中段选择(中段)

### 3.1 必带

- POV 角色在本章**中段**(全文 1/3–2/3 处)做了一次不可替代的选择。
- 选择可以是:放弃旧路径 / 接受新证据 / 公开隐藏 / 主动越线 / 拒绝让步。
- 选择必须**改变至少 1 个有名有姓角色的关系或位置**。

### 3.2 禁用

- 「她想了想,决定……」式内心独白——不是选择,是表达选择。
- 「她没有选择」式回避——晋江读者要的是「她选了 A 而不是 B」,不是「她没选」。
- 「他替他/她替他」式代替决定——禁区 6(A 听 B B 听 C)。
- 选择后无代价——禁区 4(选择不付代价)。
- 选择和前章重复——同义反复不算新选择。

### 3.3 工艺清单

- 选择必须在 ≥ 2 个 agency verb 中体现(决定 / 改为 / 改成 / 不再 / 主动 / 自己 / 签下)。
- 选择必须带 ≥ 1 个代价——身体 / 信息 / 关系 / 信用 任一即可,但不能是「没有」。
- 选择的副产物要写出来:改变了一个关系 / 改变了一个状态 / 触发了下一章必须回应的具体问题。
- 「决定」字面词不是必要,可以是动作代理:「她把那张礼单从袖里抽出来,搁在案上。」(给物即决定)
- 范文样例:第 8 回苏挽「原单不收」+ 「收货票拿出来」= 一次 M2(选择)+ M5(关系后果,她对管事的信任降温)同章叠加。

## 4. M3 · 章尾钩(章末)

### 4.1 必带

- 末段停在**动作前 / 身份误认 / 未答问题 / 新证据** 四种之一,不是泛化情绪。
- 末段必须给下一章必答的**一个具体问题**:不是「她没回」,是「她要不要把信撕开」。
- 末段不能出现「屋里很安静 / 夜很静 / 明日再看」型气氛句替代推进(禁区 8)。

### 4.2 禁用

- 末段收在「她想 / 她觉得 / 她回忆」——这是内心独白,不是钩。
- 末段是「四到五行五字句」散文断句——这是散文,不是连载断章(sub-agent A 直接红旗)。
- 末段是比喻或格言收束——比喻是天花板,不是钩子。
- 末段收在「屋里很静 / 风停了 / 雪停了」——任何「安静型氛围句」直接退稿。
- 末段没有具体动作或问题——读者读完不知道下一章要回答什么,弃读。

### 4.3 工艺清单

- 钩子的最小骨架:**她 / 他 + 一个未完成的具体动作**。例:「叶观澜拈起,没拆。」(拈起 = 已完成,没拆 = 未完成,锁两个动作)
- 章末 4–6 字短句**最多 1 行**(sub-agent A 报「5 行五字句」是连续踩雷),且必须含一个具体动作或问题。
- 章末必须有可被读者复述的具体问题:下一章要回答什么?如果读者答不出,重写。
- 不要用总结句收尾——晋江读者要的是「下一章要发生什么」,不是「这一章发生了什么」。
- 范文样例:第 505 末「蜡封上押的是沈字。叶观澜拈起,没拆。他把那封信压在棋盒盖上。不读。」(锁 拆 / 不拆,4 句全动作)

## 5. M4 · POV 主动(人物能动)

### 5.1 必带

- POV 角色本章有 ≥ 2 个 agency verb(决定 / 改为 / 改成 / 不再 / 主动 / 自己 / 签下)。
- 主动必须由 POV 角色**说或做**,不是 narrator 评论。
- 主动必须**承担一个身份后果**——她做完了,她变成了另一种人。

### 5.2 禁用

- POV 全章观察、记录、走过场——观察不是主动(sub-agent A 报「502 全章九人远观」是典型反例)。
- POV 把决定推给别人——「她等他来决定」「她等他回来」型是 POV 让位。
- POV 主动但不承担后果——禁区 4。
- 主动是 narrator 评论而不是 POV 动作——「她其实很想他」不算主动。

### 5.3 工艺清单

- agency verb 计数:每章 ≥ 2,但**不要堆 agency**——同章同 agency 词 ≥ 4 次会出现「那一 X / 自己」式回环(sub-agent A 直接红旗)。
- 主动的最小骨架:**POV + 动作动词 + 宾语 / 结果**。例:「她把糖还给他。」(她 + 把 + 还 + 给)
- 主动必须带身份后果——「还」不是动作,是关系重新称量。
- 主动的隐性表达:把「决定」字面词换成动作代理——例:「她没让管事把原单拿走」= 主动(扣押证据)。
- 范文样例:第 504「她替她哥问的话,我自己听了——我自己答了。」(agency verb 自己 x 2 + 身份后果:苏挽从「被问的人」变成「答的人」)

## 6. M5 · 关系后果(关系升压)

### 6.1 必带

- 本章 ≥ 1 对有名有姓的角色关系发生可追踪的升降。
- 形式包括:信任升降 / 亏欠出现 / 秘密兑现 / 外部事件打断关系 / 称呼变化。
- 关系动作必须在**单一可观测的句子**里发生,不是一组 frontmatter 列出。

### 6.2 禁用

- 只换观察者不换关系——关系没动,只是 POV 换了。
- 关系变化是 narrator 评论——「她对他生出几分心疼」不是关系动作。
- 关系变化是「她想到 / 她觉得他应该」——想到不是变化。
- 关系变化后没有新问题——关系变了但没有引发下章必答的具体问题。
- 同一关系在 ≥ 3 章反复「又近一寸」——关系升级必须可数、可证伪。

### 6.3 工艺清单

- 关系动作的最小骨架:**角色 A + 动作 + 角色 B + 结果**。例:「林窈把糖给了苏挽,苏挽没吃。」(给 + 没吃 = 信任转折)
- 关系后果要落到一个**具体物 / 具体称呼 / 具体姿态**——糖、信、称谓、袖角。
- 关系动作要在章末前留下可被读者复述的具体问题:她/他接下来要做什么?
- 关系后果不能只发生一次:如果一章里同一对关系只动了 1 次,要补 1 个反向动作(他给她糖,她给他帕)。
- 范文样例:第 504「林窈问糖 → 苏挽还糖 → 苏挽自己答活」(三个女人在闭环里翻转,关系动作 ≥ 3 次)

## 7. 5 模式同章叠加检测

每章跑完 5 模式后,按下列规则判定:

| 命中模式数 | 工程 E_min | 真人 R_min(若有) | 判定 |
|---|---|---|---|
| ≥ 5 模式全部 7+ | ≥ 8.5 | ≥ 7.5 | 爆款候选(若 R_min 存在) |
| 4 模式 7+ | ≥ 7.0 | ≥ 7.0 | 发布候选 |
| 3 模式 7+ | ≥ 6.0 | ≥ 6.0 | 待修 |
| < 3 模式 7+ | < 6.0 | n/a | 必须结构性重写 |

> 任一模式踩「禁用」清单 → 该模式判 0 分,与 7+ 阈值不冲突,但其它模式必须 ≥ 8.0 才能拉回总分。

## 8. 改稿操作表(从诊断到具体改稿)

| 失败模式 | 症状 | 改稿动作 | 禁用动作 |
|---|---|---|---|
| M1 开场钩失败 | 首 180 字无动作 / 阻力 | 在首句加一个具体动作 + 一个阻力词 | 不要铺环境 / 不要铺回忆 |
| M2 中段选择失败 | 中段无 agency verb | 在中段插一个 agency verb,带 ≥ 1 代价 | 不要 paraphrase 前章选择 |
| M3 章尾钩失败 | 章末收在气氛 / 比喻 | 重写末段,停在未完成的具体动作 / 问题 | 不要用比喻 / 总结句 |
| M4 POV 主动失败 | 全章 agency verb < 2 | 插 ≥ 2 个 agency verb, 由 POV 说或做 | 不要把 agency 写成 narrator 评论 |
| M5 关系后果失败 | 在场有名角色 ≥ 3 但无关系动作 | 写一对有名角色在单句里完成一个关系动作 | 不要在 frontmatter 列关系,要在正文里 |

## 9. 与已有工具的对应

- `engine/prose_lint.py` + `tools/chapter_by_chapter_audit.py` 是 M1–M5 的反向门(不 ERROR 即「没踩禁」,不证明通过)。
- `tools/jinjiang_chapter_distance.py` 是 M1–M5 的工程打分(每模式 0–10)。
- `tools/review_batch.py --strict-editorial` 是 M1–M5 的文笔 / 编辑端交叉校验。
- `tools/reader_subagent_driver.py emit` 是 5 模式在真人端的盲读协议。
- 真人盲读 `R1–R5` 是 5 模式的真人版(可读 / 钩兑现 / 关系兑现 / 主动 / 不踩禁区)。

## 10. 维护纪律

- 改 `jinjiang-edit-modes.md` 任一模式的「必带 / 禁用 / 工艺清单」 → 必须同步改 `docs/standards/晋江爆款基线.md §1` 工程 5 维表 + `tools/jinjiang_chapter_distance.py` 公式 + `tests/test_jinjiang_chapter_distance.py` 钉死回归。
- 新增 `prose_lint` 规则(sub-agent A 的 5 条工艺红旗) → 必须先在本文件登记,再写 lint,最后才修改章节。
- 真人 sub-agent 报出新的「禁用模式」 → 必须先在本文件 §2.2 / 3.2 / 4.2 / 5.2 / 6.2 追加,再升级为 lint。
