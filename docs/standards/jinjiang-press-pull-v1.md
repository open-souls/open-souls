# 晋江按压-拉抬规则 v1

> 目的：把"读者持续被按住"翻译成**两股对抗力的工程规则**。
> 按压（Press）= 把读者钉在原位的力 = 钩子、危机、代价、选择、悬念。
> 拉抬（Pull）= 把读者翻到下一页的力 = 身份动作、关系升级、章尾必答问题、兑现动作。
>
> 不替代：docs/standards/晋江爆款基线.md（双轨打分）、docs/standards/jinjiang-edit-modes.md（M1-M5）。
> 派生矩阵：§3 钩子债矩阵 = reports/jinjiang-r20/reader-debt/reader-debt-v1.md §1。
>
> 上游触发：用户原话 2026-09-06"做出那种把读者持续按住的稿子"、"设立一个新的目标，我们要做出那种把读者持续按住的稿子"。

## 0. 三句话

1. 按压是必要不充分条件；按压只能不让读者走，拉抬才能让读者翻页。
2. 按压-拉抬比 = 同章"按压事件数 / 拉抬事件数"，目标区间 1.0 – 1.6；连续 3 章比值 < 0.6 = 拉抬不足 = 掉读；连续 3 章比值 > 2.0 = 按压过剩 = 喘不过气。
3. 拉抬的最小单位是"POV 角色的不可逆身份代价"；没有这一项，按压再多也算堆砌。

## 1. 按压事件清单（press events）

> 每个按压事件必须在章中可被一句短句复述，且挂在一个具体物件 / 关系 / 物证上。
> 反例："气氛压""节奏压" = 不算按压事件。

| 类别 | 定义 | 例子（前五十章） |
|---|---|---|
| PRESS-01 钩子落地延迟 | 钩子被制造但本章不兑现 | D-01 林夙"明日再来"悬 14 章 |
| PRESS-02 关系代价 | 关系动作要求对方付代价 | ch31 苏挽揭穿假信 |
| PRESS-03 物证转移 | 一个物证进入另一个人的手 | ch8 丸药进苏挽袖 |
| PRESS-04 危机触发 | 即时危机 / 时间压力 | ch25 卯时破封 |
| PRESS-05 身份揭示 | 隐藏身份被部分揭开 | ch26 赤渊看出三百年前手法 |
| PRESS-06 阵营切换 | 某一方换立场 / 换盟 | ch32 林彻主动问"你知道多少" |

## 2. 拉抬事件清单（pull events）

> 每个拉抬事件必须在章末形成"下一章必答的具体问题"，且挂回按压事件。
> 反例："女主心情变化" = 不算拉抬事件。

| 类别 | 定义 | 例子（前五十章） |
|---|---|---|
| PULL-01 主动决定 | POV 角色本章做了一个改变局面的决定 | ch1 苏挽拒签 |
| PULL-02 不可逆身份代价 | 决定付出身份级代价 | ch14 林夙撕家纹纸主动接 |
| PULL-03 关系升档 | ≥ 1 对关系发生可见动作或代价 | ch22 林彻跪地认输 |
| PULL-04 章尾必答 | 章末提出下一章必答的具体问题 | ch11 悬赏令"纸旧墨新" |
| PULL-05 物证闭环 | 一个物证从出现到关闭 | ch40 苏挽按回半枚印泥副本 |
| PULL-06 POV 不在场 | 女主在不该在场时仍承担了身份后果 | ch20 街中一眼"祝公子还清" |

> 颜色规则：
> - **RED** = 必须在下 1 个大事件（≤ 10 章）兑现；否则掉读加剧。
> - **YELLOW** = 必须在下次相关动作时立刻兑现；可拖但不可悬过 5 章。
> - **BLUE** = 长期挂账；可放主卷之外。
> - **GREEN** = 已兑现；留底但不再追。

## 4. 按压-拉抬比（P/P ratio）

```
P/P ratio = 同一章内的 PRESS 事件数 / PULL 事件数
目标区间：1.0 ≤ ratio ≤ 1.6
连 3 章 ratio < 0.6  → 拉抬不足（ch11、ch12、ch13、ch20 是典型）
连 3 章 ratio > 2.0  → 按压过剩（ch41-44 是典型）
单章 ratio = 0      → 完全不按住，必须补 PULL
单章 ratio ≥ 3      → 完全不让翻页，必须补 PRESS 落地
```

> 前五十章按段统计：
> - ch1-10：平均 1.4（含 ch7、ch9、ch10 三章拉抬偏弱）
> - ch11-20：平均 0.7（掉读窗口起点）
> - ch21-30：平均 0.9（掉读窗口底点）
> - ch31-40：平均 1.3（短暂回升，ch34-39 又掉）
> - ch41-50：平均 1.9（按压过剩，ch44 包子那章是 2.7）
