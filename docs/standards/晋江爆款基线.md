# 晋江爆款基线 · 工程 + 读者 双轨

> 目的：把"晋江爆款 / 上瘾"翻译成可被机器门与读者盲读同时验证的判定基线。
>
> 适用：单章 / 单包 / 单季。
> 不替代：`docs/standards/rubric.md`（章级评分）、`docs/standards/playbook.md`（桥段库）、
> `docs/standards/文笔范文标准.md`（七维 + 范文）、`docs/standards/雅俗共赏.md`（双层文本）。
> 与读者工作流：`docs/reader-subagent-workflow.md` 是本基线的真实读者证据通道。
> 升级阈值与复读去重：见 `docs/reader-subagent-workflow.md §7`，不能把 L1 复读当真人共识。

## 0. 三句话

1. 工程分不是市场分，但工程分 < 基线的章节**没有资格**进入真人盲读池。
2. 真人盲读分不是市场分，但真人盲读 < 基线的章节**没有资格**进入下一轮发布候选。
3. 工程分 + 真人分同时 ≥ 基线才进入"候选爆款"；**取两者的最低值**作为最终判定。

## 1. 工程 5 维（每维满分 10）

> 全部由 `tools/jinjiang_rubric.py` 与 `tools/chapter_by_chapter_audit.py` 自动打分。
> 任何一维 < 7 → 该章不进入真人盲读池。

| 维 | 含义 | 7.0 门槛判据 |
|----|------|------------|
| **E1 开场冲突** | 第一段必须出现动作 + 阻力 | 开篇 180 字内 ≥ 2 个动作动词 + 出现"却 / 但 / 没有 / 拦"等阻力词 |
| **E2 中段选择** | POV 角色本章做了一次真正改变局面的选择 | 中段出现"决定 / 改为 / 改成 / 不再 / 主动 / 自己 / 签下"等主动选择词 |
| **E3 章尾钩子** | 末段停在动作前一寸 / 身份误认 / 未答问题 / 新证据 | 末行匹配"忽然 / 却 / 没[有再]? / 门外 / 脚步 / 声音 / 信 / 敲 / 未完"任一 |
| **E4 人物主动** | POV 角色本章有可见决定 | 主动选择词 ≥ 2 |
| **E5 关系后果** | ≥1 对人物关系发生可追踪的升降 | 在场有名有姓角色 ≥ 3 + 中段选择词命中 |

**5 维同章打分取最低值**作为该章工程总分。≥ 7 进入盲读池，< 7 必须先修。

## 2. 真人盲读 5 维（每维满分 10）

> 来源：`docs/reader-subagent-workflow.md`。
> 由 5 份 L1（模型代理）+ ≥1 份 L2（真人 sub-agent / 真人读者）共同给出。
> 只有 `source`、`isolation`、`schema_version`、`model_id`、`reading_log`、`pack_hash` 均齐全时，L2 才计入；文件名不算证据。
> 任何一维 < 7 → 该章不进入发布候选。

| 维 | 含义 | 7.0 门槛判据 |
|----|------|------------|
| **R1 跨题材可读** | 跨题材读者（persona 3）60% 章节独立可读 | persona 3 给出 stay_to_50=true 或给出明确留下理由 |
| **R2 钩兑现** | 章末必须给下一章必答的具体问题 | ≥3 份读者追问同一章 / ≥1 份追问同一章 + 给出具体问题 |
| **R3 关系后果兑现** | ≥1 对关系有可见动作或代价 | ≥1 份读者追问同一关系 + 给出具体期待 |
| **R4 主动选择** | POV 角色本章做了 ≥1 个明确选择 | 主动选择词 ≥ 2 + 真人分 ≥ 7 |
| **R5 不踩禁区** | 三键 flag 中"降智 / A 听 B B 听 C" 命中数 = 0 | smart_drop=false 且 passive_chain=false |

**5 维同章打分取最低值**作为该章真人总分。≥ 7 进入发布候选。

## 3. 不可越线的边界

下列任一命中 → 该章**直接退回**重写，不计分：

- **禁区 1**：静物承担情绪却不推动行动（"屋里很安静"型承担）。
- **禁区 2**：连续 5 回首句结构相同。
- **禁区 3**：主角掌握证据后突然降智。
- **禁区 4**：POV 角色做选择但不付代价。
- **禁区 5**：旧账/信/玉/糖只作线索、从不变行动。
- **禁区 6**：A 听 B，B 听 C，C 听 D，没人做决定。
- **禁区 7**："替谁守""替谁记"成为动作的后置解释。
- **禁区 8**："屋里很安静""夜很静"等气氛句替代推进。

来源：`reports/jinjiang-r20/jinjiang-rubric.md §3` + `tools/chapter_by_chapter_audit.py`。

## 4. 编辑判断五问（每章必答）

1. 谁要什么？。POV 角色的核心欲。
2. 谁阻止？。可被读者复述的阻力。
3. 付出什么代价？。不能填"没有"。
4. 章尾读者必须追看的下个问题是什么？
5. 本章是否改变了下一章的开局位置？没有 → 重写。

来源：`reports/jinjiang-r20/edit-decision-protocol.md §1`。

## 5. 上瘾单元（每 5–10 回一个）

每个上瘾单元必须包含：

- 一个**可见冲突**，不只是气氛。
- 一个 **POV 角色的主动选择**。
- 一个**不可逆的信息或关系后果**。
- 一个**未完成的新问题**。

> 上瘾单元缺失，章节再多也只是篇章集合。读者不会追。

## 6. 双轨打分的合并公式

```
最终分 = min(工程 5 维最低维分, 真人 5 维最低维分)
发布门槛 = 最终分 ≥ 7.0
"爆款"门槛 = 连续 3 章以上 ≥ 8.5
"上瘾"门槛 = 连续 5 章以上 ≥ 8.5 + 真人 5 维全部 ≥ 7.5
```

> 任一门槛未达，禁止在报告里使用"上瘾""爆款""读者会追"等判断。
> 工程 9.8 ≠ 市场分；真人 8.5 + 工程 6.0 = 仍 = 6.0。

## 7. 与机器门的关系

- `engine/prose_lint.py` 是地板（不 ERROR），过了 lint 不等于合格。
- `tools/chapter_by_chapter_audit.py` 是初筛（issue tag + binge_score）。
- `tools/jinjiang_rubric.py` 是工程 5 维打分。
- `tools/reader_panel_runner.py` 是真人 5 维聚合。
- 四道门缺一不可，按 lint → audit → rubric → panel 顺序串行。

## 8. 与下一季的关系

- 老季（`legacy_mode: true`）只作为素材与审计对象；不要求本季达标。
- 新季必须设置 `human_decision_required: true` 与 `legacy_mode: false`，且至少有一个上瘾单元先跑通本基线 E1–E5 + R1–R5。

## 9. 不允许的省略

- 不能用工程分替代真人盲读。
- 不能用真人盲读替代工程分。
- 不能在缺任一分的情况下宣称"爆款 / 上瘾"。
- 不能把单次读者会话的判断当成多读者聚合。
