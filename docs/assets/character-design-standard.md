# 《众魂 · 镇狱之渊》角色美术标准

> 版本 1.0 · 2026-08-13

角色实体边界见同目录的 [角色实体清单](character-entity-registry.md)。角色谱以具名或已被正文锁定的稳定实体为准；“那个人”“母亲”“随从”等泛称不自动生成独立脸，避免把叙事标签误做成虚构角色。

这套标准解决的不是“把人物画得更漂亮”，而是让读者能在没有名字的情况下认出角色：先用小说证据建立身体、动作、物件和关系，再用水墨半仿真渲染。参考图只作为媒介与笔触参考，不复制任何具体人物、构图或受版权保护的造型。

## 1. 总体方向

**墨为结构，白为呼吸，色为证据。**

- **媒介**：中国水墨、炭笔、宣纸颗粒与少量半仿真皮肤/布料质感的混合；线条要有干湿、轻重、断续，不做均匀的“滤镜水墨”。
- **气质**：克制、有人在场的重量、动作先于姿势；允许疲惫、偏头、驼背、手不漂亮、衣服有磨损。
- **色彩**：骨白、烟灰、炭黑为底；角色只保留 1 个可追踪的低饱和色点（冷玉、旧青、靛蓝或朱砂）。颜色必须服务于身份、道具或剧情，不做装饰性渐变。
- **构图**：大量留白、非对称、不同高度和不同朝向。群像不排成海报式一字排开。单人设定图可横向或纵向排版，但三视角必须完整可见，不能为了卡片比例裁掉侧面、背面或道具。
- **现实感**：角色设计可以更真实、更有年龄与体态差异；最终渲染保持绘画性，不走真人照片，也不走网红脸/二次元大眼。

## 2. 每个角色的标准交付

每个核心魂和可辨识的重复 NPC 都必须有一张独立设定图，文件名为 `char_<slug>_sheet.png` 或 `npc_<slug>_sheet.png`。一张图内固定包含：

1. 正面三分之二全身：读者第一次认人的主视图。
2. 侧面轮廓：检查鼻梁、下颌、发型、肩线与道具是否独立。
3. 背面三分之二：检查衣服结构、发束、腰牌、刀鞘和行走重量。
4. 至少一个局部手部/道具关系：角色“怎么拿”比“拿了什么”更重要。
5. 同一角色在三个角度中的脸型、身高比例、年龄、服装层次和道具必须一致。

图内不放姓名、标题、说明文字或水印。文字、年龄、阵营、关系与版本由同目录的 `manifest.json` 和角色卡维护，避免生成图里的伪汉字破坏可信度。

## 3. 身份锚点（生成前必填）

每个角色至少固定以下 8 项；未知项必须写“未知”，不能用模板化仙侠装补齐：

| 锚点 | 需要回答的问题 |
|---|---|
| 体态 | 高矮、胖瘦、肩胯、伤病、站/坐的重心是什么？ |
| 脸型 | 年龄感来自哪里？不要只写“俊美/清秀”。 |
| 发型 | 发束如何固定？散发是状态变化还是默认造型？ |
| 服装 | 外层、内层、磨损和穿法有什么可复用的差异？ |
| 手 | 手指、茧、伤、动作速度和习惯是什么？ |
| 道具 | 哪件物必须一直存在？它如何被拿、压、藏、放下？ |
| 行走 | 安静、拖沓、踩砖缝、靠墙、坐轮椅，哪一种最像他/她？ |
| 关系色 | 仅保留一个低饱和色点，并说明它对应什么叙事证据。 |

## 4. 禁止项（反 AI 视觉门）

- 同一张“标准古风美人脸”套给所有人；年龄、骨相和性别气质必须拉开。
- 过度磨皮、玻璃眼、对称五官、商业棚拍高光、统一的电影蓝橙光。
- 没有功能的长飘带、金色铠甲、珠宝堆叠、发丝瀑布、悬浮粒子和无意义法术光。
- 所有人都正面站立、看镜头、微笑或摆出“海报英雄姿势”。
- 用大段伪汉字、错误印章或英文提示词残影做装饰。
- 用服装颜色代替人物性格；颜色只能强化已有的身体/道具/剧情证据。
- 为了“水墨感”把脸、手、关节和轮椅/刀具画糊。墨可以断，结构不能断。

## 5. 网站使用规范

- 首页主视觉只使用有留白的群像或场景图，标题由 HTML 排版，不把中文标题烧进图片。
- 角色谱使用独立设定图卡片，默认显示姓名、身份、出场回数和“主锚点”一句话；图片只作为可读的视觉证据，不替代角色档案。
- 所有图片放在 `docs/assets/characters/`，线上页面通过相对路径引用，便于 GitHub Pages 直接发布。
- 角色卡片不能把所有人压成同样的头像圆框；采用不同裁切、不同留白和不同色点，保留设定图的呼吸。
- 新一季换世界时保留魂的动作/裂缝锚点，只替换皮囊、服装和世界道具；同名角色不可直接复用上一季的脸。

## 6. 生成与审核流程

1. 从 `souls/<角色>/soul.md`、`dossier.md`、`npcs.md` 和正文锚点提取证据。
2. 先写身份锚点，再写图像提示词；禁止先生成漂亮图再倒推性格。
3. 生成三视角设定图，检查三视角是否是同一人、道具是否连续、年龄和体态是否可信。
4. 用 25% 缩略图检查轮廓：不看脸时仍应能区分至少三个主角。
5. 用灰度检查明暗：黑白关系必须可读，不能靠颜色识别人物。
6. 失败即重生成，不用 CSS 滤镜把失败图“修成水墨”；除裁切、压缩和无损格式转换外不做改变身份的后处理。

## 7. 命名与版本

```text
docs/assets/
  character-design-standard.md
  characters/
    manifest.json
    char_linsu_sheet.png
    npc_yeqingwu_sheet.png
  images/
    hero-inkwash-v2.png
```

如果要重做，不覆盖旧稿，使用 `_v2`、`_v3` 后缀；`manifest.json` 中只把经过人工视觉检查的版本标记为 `ready`。
