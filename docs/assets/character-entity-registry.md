# 角色实体清单

这份清单解决一个容易被“全员角色设计”掩盖的问题：正文里出现的每一个人名、关系称谓、群体称呼，并不都等于一个可以独立定脸的角色。

## 覆盖范围

- 数据依据：`docs/chronicle.json`、`souls/*/soul.md`、`souls/*/dossier.md`、`seasons/01-xianxia/npcs.md`。
- 当前角色谱：49 张独立设定图，其中 21 个核心 `soul`、28 个具名或已被正文锁定身份的 `NPC`。
- 每张图都必须是独立文件，并包含正面 / 四分之三侧面 / 侧面或背面 / 手部或道具关系；合图只可作为过程草稿，不能代替角色卡。
- `清梧`是`叶清梧`的正文别称，合并为一个实体，不重复画两张脸。
- `老周`、`门房老周`、`库房老周`合并为林家老周；`旧仆`不与老周合并，单独作为叶观澜身边的长期旧仆参考卡。
- `容昀`虽然是核心魂，但当前 `chronicle` 的 cast/present 没有把他稳定写入正文出场统计；他的设定图仍保留，出场数显示为 0，不伪造数字。

## 为什么不是把所有出场标签都画成独立的人

截至当前 `chronicle.json` 的 1000 条记录，原始 `cast` / `present` 标签包含了正文角色、关系称谓、群体、场景状态和生成元数据。比如 `林夙(倒在地`、`叶观澜(山顶` 这类括号标签要归一回同一角色；而 `那个人`、`母亲`、`宗门众人` 则不是可安全合并的个人姓名。给这些标签强行定脸会制造不在原文里的设定，也会让网站看起来像批量 AI 头像墙。

以下标签暂不建立独立角色卡：

| 标签 | 处理 | 原因 |
| --- | --- | --- |
| `那个人` | 叙事代词 | 没有稳定指代对象或可复用外形 |
| `母亲` | 关系称谓 | 只在亲属关系中出现；与王姨娘的对应关系需要正文继续确认 |
| `老人` | 泛称 | 不是稳定姓名；已将有明确场景身份的糖铺老人单独建卡 |
| `师父` | 泛称 | 不是稳定姓名；已将“凌朔师父”作为可辨认实体单独建卡 |
| `老仆` | 泛称 | 不能擅自等同余伯；已把有长期稳定关系证据的叶观澜旧仆单独建立角色参考卡 |
| `随从`、`守卫`、`使者` | 职能称呼 | 可由场景需要临时绘制，但不进入角色谱 canon |
| `蛊场管事` | 场景职能 | 目前只有一次场景职能，没有足够可复用的个人信息 |
| `苏家来人`、`宗门众人` | 群体 | 应保持群像差异，不合并成一个虚构人物 |

以下无名标签虽然没有姓名，但已经被单独锁定为“角色参考”，不是声称他们有 canon 姓名：

| 标签 | 角色参考卡 | 依据 |
| --- | --- | --- |
| `归隐谷信使` | 已建立 | 在多个章节承担稳定的职业动作、服装和递信关系 |
| `叶家随从` | 已建立 | 有稳定服务姿态、递帖动作和叶观澜的关系位置 |
| `旧仆` | 已建立为“叶观澜旧仆” | 长期站在叶观澜身边，缝线、收信和沉默是可复核锚点；不与林家的老周混为一人 |
| `借买腰牌的人` | 已建立 | 单章但有明确身量、斗笠、外八步和腰牌袋等可复核外形证据 |

`周平`、两位不同语境的`姜氏`、`济和堂掌柜`、`药铺掌柜`属于正文已明确身份或动作的短线人物，因此也各自拥有独立设定图。两位姜氏绝不共用一张脸。

## 进入角色谱的规则

只有满足以下任一条件，才新增独立角色卡：

1. 有稳定姓名或稳定专名；
2. 虽无姓名，但在正文中拥有持续的场景身份、可重复出现的行为和明确道具；
3. 文本明确把关系称谓锁定为某个具体人，并且后续能复核。

新增前先在本文件登记证据和别名，再生成图片、加入 `manifest.json`，最后在本地页面检查角色卡、原图链接和移动端布局。

## 视觉执行边界

角色设计可以比最终渲染更接近真实的人：年龄差、骨相、体态、手部劳损、衣物磨损都要可见。网站渲染统一收敛到水墨半仿真：宣纸肌理、墨线结构、灰阶体积、少量朱砂 / 青黛 / 旧棕作为叙事证据；禁止用“同一张漂亮脸 + 换衣服”代替人物设计。
