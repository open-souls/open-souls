## 〇、v3 grader 关键修复

### 0.1 v2 grader bug 发现

跑完 v2 grader 数据后，发现两个系统性 bug：

| Bug | v2 行为 | 影响 |
|---|---|---|
| **pub.4 cast3-5 反向** | cast≥5 给 0 分，cast≤2 给 2 分（和目标"3-5"完全反向） | 96% 章都被错判为"cast 不对"，实际很多章是 3-5 个 |
| **rubric.3 反差关键词太严** | 只检测"不X但/却" + 高矮/大小/满空/冷热 直接邻接 | 100% 章都判 0，因为大多数文学写作用了"高/矮"对比时不会邻接 |
| **rubric.4 拉扯** | 只看"替她/替他/看见"模式字 | 87% 章判 0，忽视 "他没X她/她没X他" 推拉 |
| **d7.7 克制** | 只检测特定句式"那一刻她明白" | 98% 章判 1，没识别"作者代为点破" |

### 0.2 v3 grader 修复要点

1. **pub.4 cast3-5 改成正向**：cast 3-5 给 2 分，2 或 6 给 1，其他给 0
2. **rubric.3 反差 扩展 12 标记**：高矮/大小/满空/冷热/旧新/内外 + 不X但/却 + 三段式（一个失败/一个成功/还有一个）
3. **rubric.4 拉扯 扩展**：替/不替/看见/不替看见 + 没答/没接/没继续 + 担心/担忧/报告 + 等他/等她
4. **d7.7 克制 新增"作者代为点破"检测**：她在...上/是他...的/那是...的
5. **新增 sh 上瘾 6 维**：
   - sh1 末句钩子 (动作/物象/未完成)
   - sh2 末句物象留白
   - sh3 情绪波 (甜+刀 ≥3+3)
   - sh4 CP 推力节拍
   - sh5 女主/POV 能动性
   - sh6 悬念 carry (末 30% 新信息密度)

### 1.3 lift 用的 7-pattern（ch217 + ch851 提取）
