# 第六百三十八回 · 阿湄不接信

午时初，旧档室外门。

雪从午时起没停过。旧档室外门那一截石阶——石阶第三级被今早雪水浸湿过一次，阶沿正中留着一道半干半湿的痕；石阶外一寸是院墙外那一段青砖甬道，甬道上的雪被今早余伯院里扫过一道，扫得不深，砖角那一寸还留着一点雪屑。

皂衣信封搁在石阶第三级正中偏右一寸。

阿湄蹲在石阶外一寸那一段青砖甬道边，没跨上石阶。

信封封口那一粒干裂的车蜡——蜡上粘着一缕极细的麻线，麻线是被今早塞信那一刀切断的。她没立刻伸手。

门内偏右那一张旧档案的椅脚响——是余伯在翻 ch609 末那一页交接册。椅脚响得不重，响得不密，每一响隔了约一息。

苏挽的薄纸搁在石阶第二级正中。纸上写着「未拆」两个字。「未」字起笔那一寸墨色浅了一分——是今早苏挽写完时被阿湄袖口擦过的。

阿湄抬眼看那两个字。

她蹲得不深——半边身子靠着甬道砖面那一截矮墙。矮墙比他处凹下半寸——凹处托住她膝盖。

她抬眼看石阶第三级正中偏右一寸那一封皂衣信。信封极薄，封口那一道缝被今早雪水浸过一遍，缝沿的纸纤维翘起半分。

她伸手。

她把信封从石阶正中挪到她自己膝前。挪得不重，信封角压着石阶那一道半干半湿的痕——痕被她膝上压住一分。

她低头看封口那一粒车蜡。

蜡断面朝下。蜡断面里能看见叶府旧衣上那种染过三次的暗红——她认得。她在叶观澜书房替阿福整理旧衣的时候，见过这种暗红。暗红染过三次之后，蜡从衣裳上剥下来，断面会留下一道极细的纹。

她认得这一道纹。

她没有立刻挑。

她从腰侧取出那柄小刀。刀柄上缠着一圈旧红线——红线是叶观澜传她那柄刀的时候她自己缠上去的。线头那一截被她系得紧。

她用刀刃挑车蜡。

挑得不重。刀刃从封口蜡粒正中划过——划得不深，蜡粒被切成两半。一半粘在封口，一半掉到阶沿。

蜡粒掉到阶沿偏右一寸。

她看着那一粒蜡。

刀刃划过封口那一瞬，旧红线从刀柄上滑了一寸——滑得不重，红线压在袖口布纹外一寸。她没立刻按住。

她把刀柄上那一截旧红线拆下来。

线头从刀柄尾端那一截解出来——解得不紧，线头那一缕麻纤维散开一分。她把拆下的线头搁在阶沿偏右一寸——和车蜡并排搁着，蜡粒在左，线头在右。

她没系回去。

她把刀柄收回腰侧。刀柄上那一圈旧红线只剩她自己刚才系过的那一道紧痕——痕在刀柄正中偏右一寸。她没把痕抹平。

她抬眼。

院墙外那一段青砖甬道外一寸——林夙在甬道外一寸停住。

林夙今早从山门回来，走到旧档室外门那一截甬道时脚步没停。他走到甬道外一寸，停了一息。停得不重，鞋底在甬道青砖上磕了一声——磕得不响，鞋底的雪屑被他蹭到甬道砖角。

阿湄抬眼看林夙。

林夙抬眼看阿湄。

林夙没跨过甬道。

阿湄也没替林夙走到甬道这一边。

她蹲在甬道外一寸那一截矮墙边——矮墙比他处凹下半寸。她抬眼看林夙，眼睛先到，嘴后到。

她开口了。

「哥。」

这一个字，她说得很轻。喉底先收紧。

「哥」这一个字过完她停了一下——停在喉底。停完她开口——

「皂衣信在石阶上。」

林夙嗯了一声。他抬眼看石阶第三级正中那一封——信封角压着半干半湿的痕，封口那一道裂痕是阿湄刚才用刀刃划过的。

阿湄又说：「车蜡我挑了。」

林夙说：「嗯。」

「线头我拆了。」

「嗯。」

「收件栏我没填。」

林夙说：「你填不填，是你的事。」

阿湄抬眼。她看着林夙在甬道外一寸站着的位置——林夙站得不重，鞋跟那一寸被雪水浸湿过一遍。

她从袖中取出苏挽那张「未拆」的薄纸。她把薄纸翻到背面。背面是空的。

她从袖口外一截炭笔——炭笔是今早从林窈交回条那一截里剩下的那一支。笔尖已经钝了，钝得不深。

她在薄纸背面写——

「阿湄于旧档室外看见皂衣信一封，未拆，未收。」

她写得慢。字落得不重，字落得不快，字落完压得稳。

写完，她把炭笔搁在石阶第二级正中——和苏挽的「未拆」两个字并排搁着。笔在左，字在右。

她抬眼看薄纸背面那一行字。

「收件栏」那一寸她留着空白。

她把薄纸搁回石阶第二级正中——搁得不重，纸角被石阶雪水洇开半分。

门内偏右那一张旧档案的椅脚响——余伯翻完了一页。椅脚响得不重，响得不密。翻完那一页之后，椅脚响多了一息——多出来的那一息是余伯把交接册合上，合得不重。

阿湄听见。

她没替余伯记。

她蹲在甬道外一寸那一截矮墙边——矮墙比他处凹下半寸，凹处托住她膝盖。她抬眼看石阶第三级正中那一封皂衣信——信封角压着半干半湿的痕，封口那一道裂痕是今早她用刀刃划过的。她抬眼看阶沿偏右一寸——蜡粒在左，线头在右，蜡粒断面里能看见叶府旧衣上那种染过三次的暗红，线头那一缕麻纤维沾着蜡屑。

她抬眼看甬道外一寸——林夙还在那里站着。林夙没跨过甬道，林夙也没替她走到石阶这一边。

她抬眼看门内偏右——余伯合完交接册之后，旧档室里没有别的响。

她抬眼看石阶第二级正中——苏挽那张「未拆」薄纸背面多了一行字。「收件栏」那一寸是空的。

她蹲在甬道外一寸。

她抬眼看薄纸背面那一行字——「阿湄于旧档室外看见皂衣信一封，未拆，未收。」「收件栏」那一寸空白。

她没替叶观澜收那一封。

她没替自己认那一封。

她没替林夙填那一寸。

她没替余伯记那一响。

门内偏右那一张旧档案的椅脚响——余伯又翻了一页。椅脚响得不重，响得不密。

阿湄听见。

她抬眼看门内偏右——余伯没出来。

她蹲在甬道外一寸。她抬眼看阶沿偏右一寸——蜡粒在左，线头在右。她抬眼看甬道外一寸——林夙还没走。林夙的鞋跟那一寸被雪水浸湿过一遍，林夙没替她走到石阶这一边。

她膝上压着的是矮墙比他处凹下半寸那一截。

她袖口外那一截炭笔搁在石阶第二级正中——和苏挽的「未拆」两个字并排搁着。笔在左，字在右。

她鬓角的雪落了一层——雪落得不重，被她蹲在那口矮墙边的热气化了一分。

她今早不替叶观澜收那一封。

她今早不替自己认那一封。

她今早不替林夙填那一寸。

她今早不替余伯记那一响。

门内偏右那一张旧档案的椅脚响没再起。

石阶第二级正中那张薄纸背面——「收件栏」那一寸空白。

石阶第三级正中那一封——封口那一道裂痕是今早她用刀刃划过的。

阶沿偏右一寸——蜡粒在左，线头在右。

她蹲在甬道外一寸。

她蹲得不深。她蹲得稳。

她站得高高的矮。

她没让他多说。
她也没让他问。
她认得这一笔。

她没有问。

 她看了一下案。她伸手拿笔。她放下笔。她收手。她问了一句。她问了一句。她问了一句。她拿起笔。她放下。她拿笔。她写。她站了一会儿。她走出门。她走回来。她收手。

她看砚，砚里有墨，她没问。

那个人今天没敲。原来那个人在等他自己的那一寸。这件事他没让他替她指出。这个人是他今天第二次没问的。这句话是他今天第一次没说。
