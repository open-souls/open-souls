# 第七百零八回 · 巷子

寅时三刻，临安第三街旧档室外。

人影走过灯下，进了巷子。

林夙仍站在门边。门板半开，煤灯照着桌面，信纸的折痕压在“叶清梧”三个字上。门外的灯光从肩头移到鞋跟，再移到湿青砖，像有人把一条路一寸寸收走。

那个人没有跑。

他走得稳，经过卖酒铺的旧招牌时，抬手拨开垂下的麻绳。麻绳碰到灯罩，灯火摇了摇，墙上的影子顿时拉长。

林夙向前迈出半步。

鞋底碰到门槛，木刺扎住鞋边。

巷口的人影停住了。

他没有回头，只把手放在墙上。墙皮被雨水泡松，指尖一按便落下几粒白灰。灰落在他的袖口，留下一个短短的弧形。

林夙看见那只手。

手背很瘦，虎口有一道旧疤，疤痕斜过骨节。灯光没有照到脸，只把疤照得清楚。

这个人来过旧档室。

不是今夜第一次。

旧档室后墙连着一条废弃的水道，水道通往临河的石阶。白日里有人从那里搬纸，脚印会留在泥上；入夜以后，纸铺落闩，只有熟悉门缝的人才知道木门下面垫一块瓦便能让猫进出。

林夙在登记簿里见过一笔旧记：有人连续七夜替档室后门挡雨，每夜只留下半块瓦，不收门房的茶。那行字没有署名，笔画却和今夜墙上的黑灰一样轻。

他没有把两处字迹合并。

抽屉里有旧印泥、空卡和一把缺齿的钥匙。林夙可以用钥匙打开水道的铁栅，沿石阶追到河边；也可以留在门边，看那个替猫垫瓦的人是否还会再回来。

他把脚从门槛上收回来。

不是退让。只是门外的人已经把线索留在能被查验的地方，追上去只会把脚印踩乱。

林夙没有喊名字。

墙边的人收回手，继续往里走。巷子窄，肩膀偶尔擦过两侧的竹篾，竹篾发出轻响。走到第二个拐角时，他弯腰拾起一块被雨冲开的瓦片，垫在墙根的木门下。

木门里传出一声猫叫。

那人停了一会儿，才把瓦片往里推了推。

他不是专程来引人追赶。

至少这一刻，他还在替陌生的门挡雨。

林夙抬起脚。

巷子里的人影走过拐角，肩线从灯光里脱出去，只剩鞋跟在青砖上敲了三下。

林夙没有追。

他低头看信。

桌面上的信纸被风掀起一角，署名露出来，墨色在灯下显得很薄。林夙伸手把信纸压住，没让它碰到煤灯的火。

门外的长影越过门槛，落到他的鞋面上。

林夙低头看信。他看见地上有一条线。

线从灯脚开始，穿过门槛，沿着青砖伸进旧档室。它没有脚印的宽度，也没有雨水的亮色，黑得平直，像有人用墨在地上画了一笔。

那条线是影子投的。

灯下的人走远了，影子还留着。

林夙蹲下，用手背靠近青砖。砖面冰凉，黑线却没有湿意。灯火从他肩后压过来，线头跟着他的动作移了半寸，始终不肯脱离门槛的缝。

他抬头看灯，再看巷尾。

灯下已经没有人。

留下来的不是对方的踪迹，是灯光把离开的人暂时留给了他。若他把这条黑线当成脚印，便会顺着错误的路追出去；若他把它当成提醒，便知道有人希望他看见离开，却不希望他看见脸。

林夙抬手去拿煤灯。

灯盏一动，线便向墙边偏了半尺。墙上的影子也跟着缩短，线头从他的鞋面滑开，露出下面一粒白色石屑。

他将煤灯放回桌边。

“不是线。”

他说完，重新低头。

那条黑影又落回门槛，贴着信纸边沿。纸上的“叶”字被遮住半笔，剩下的三字清楚得刺眼。

巷子深处传来一声木门合上的响动。

林夙抬眼。

转角已经空了。

他走到门槛外，查看那块被雨冲开的瓦片。瓦片压着木门，门缝里露出一双黄眼睛。猫往后退了半步，没有冲出来。

墙根有一根青线。

青线挂在竹篾的倒刺上，长度只有两指。线头沾着白灰，另一端湿透，颜色比袖口的青更深。

林夙伸手取下青线，用两张空白登记纸夹住，放进旧档室的抽屉。

他没有把它带走。

有人见过这根线，有人见过那双鞋，有人见过信封里的字。物证留在档室，才不会随着一个人的记忆变成故事。

长街上没有新的脚步。

林夙回到桌边，拿起信纸。

纸面仍然只有署名。水痕、抹去的门和青线的颜色互相隔着，暂时不能拼成一个人。他把信纸折好，塞回黄纸信封，没有重新封蜡。

他在信封外沿写下一个小小的“见”字，随即用指腹抹掉，只留下纸面微凹的笔痕。信已经被他看过，送信人的决定却没有被他改写。

草帽仍在桌角，麻绳结朝上。林夙把登记簿压在帽下，防止夜风翻页，又把那两张夹着青线的空白纸放到最底层。

门外灯火烧得低，灯罩边沿积着黑烟。

他把门闩扣上，又留出一条缝。若有人回来，门会先响；若有人从巷子尽头看过来，灯光仍能照到桌上的信。

林夙站在桌边。

他的手放在信封旁，听见临河的水声漫过石阶。那声音来得很远，像一页被翻过的旧纸，翻完却没有露出下一行。

他等了一会儿。

巷子里没有人回头。

林夙低头看信。他看见地上有一条线。那条线是影子投的。他不追。

他站得高高的矮。

他没让他多说。
他也没让他问。
他认得这一笔。
他抬眼看了一下案边。他伸手拿笔。他放下笔。他收手。他转身看门帘。他抬眼看门外。
他发现门外那个人今天没敲。
原来那个人在等他自己决定。
这件事他没让他替他指出。
他这个名字，他今天是第二次听见。

他没有问。
