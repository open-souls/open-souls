# 钩子债兑现账索引

本目录只记录钩子如何在正文中形成可核对的因果闭环。L1 识别出债务不代表真人反馈，也不代表市场表现。每次关账都要回填 `reports/jinjiang-r20/reader-debt/reader-debt-v1.md §1` 与 `docs/standards/jinjiang-press-pull-v1.md §3`。

## 关账触发条件

一条债务只能在同一条正文事件同时包含以下五项时关账：

1. 压力：原钩子带来的具体人、物或期限进入场景。
2. 选择：女主或当章 POV 明确选择处理方式。
3. 代价：选择造成身份、关系、资源、信息或时间的不可逆损失。
4. 状态变化：人物、物证、阵营或关系的状态可被下一章复述。
5. 下一压力：由该动作自然产生具体问题，且不是同一谜面换词重挂。

## 单条兑现账模板

每次关闭或部分关闭债务，创建 `D-XX-chNN.md`，内容至少包括：

```markdown
# D-XX · <钩子名> · chNN

- 原债：<首现章、原句或物证>
- 压力：<本章中谁、什么物或期限逼近>
- 选择：<女主或当章 POV 的明确决定>
- 代价：<不可逆身份、关系、资源、信息或时间代价>
- 状态变化：<本章结束后哪些事实已改变>
- 下一压力：<由上述动作直接产生的具体问题>
- 反证条件：<什么出现时不能称为兑现>
- 正文证据：<章节文件和短引文>
```

## 维护规则

- 未创建对应兑现账，不得把债务标为“已兑现”。
- 只写“人物知道了”不构成关账，必须出现选择和可见代价。
- 同一事件可关闭多条债，但每条债都要各自说明正文证据和状态变化。
- 若债务要继续悬停，必须在改稿记录中写明负责兑现的章节和事件，不能只写“后文解释”。
