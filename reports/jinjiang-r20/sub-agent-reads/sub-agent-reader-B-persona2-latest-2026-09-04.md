## 2. 跨章重复同点（persona 2 真正会烦的地方）

按读到顺序累计，下面这些点反复出现，是这一段在「追更」维度上最容易让人疲倦的原因：

- **「不替你补空 / 我只写看见的」** 在 1140 / 1141 / 1139 / 1142 / 1138 至少 5 章几乎原话重出，是 10 章最显眼的一句台词逻辑。
- **「门槛不落 / 半寸 / 一停」** 是 1145 / 1141 / 1143 三章共享的同一动作意象。
- **「朱圈 / 朱笔 / 红粉 / 红蜡 / 血色」** 在 1137 / 1142 / 1143 / 1144 反复出现，但每次都没有把「朱 = 苏挽」这件事给读者一个明确兑现的瞬间。
- **「叶」字链** 横跨 1140 / 1141 / 1139 / 1138 共 4 章，钩子最重但兑现最弱；persona 2 一旦读到第 4 个「叶」字还没拼出全名，会开始怀疑作者在拖。
- **「上一世 / 这一世 / 替谁守那一寸」** 在 1143 / 1144 / 1138 三章高密度回响；如果再叠 1142 的「今夜子时」，读者会分不清时间线到底是谁替谁在哪儿。
- **阿湄的角色「我只是经手，我不补理由」** 在 1137 / 1140 / 1141 / 1142 / 1143 / 1144 六章以几乎相同动作（按纸角 / 落名 / 不答 / 蹲下 / 转身）出现，是这 10 章人物层面最强的复读嫌疑。
- **章末「不是 X，是 Y」的反转句式** 在 1140 / 1137 / 1141 / 1139 / 1138 都出现，钩子统一但是钩子形状完全一样；persona 2 在读到第 4、5 次时不会觉得「反转」，只会觉得「又是这套」。

> persona 2 的真实风险不在单章钩子弱，而在连续 10 章钩子形状几乎一样。一旦超过 7–8 章不出现一种新的钩子类型（具象物兑现 / 第三方揭晓 / 兑现朱圈 / 给叶清梧一个明确姓名），敏感读者会从「追」掉到「翻」。
