## 1. CP 关系每 2-3 章是否有可追踪升降

- ch1：撕毁婚约 + 递碎纸 + "明日再说"，关系从陌生转为对抗性关注。
- ch2：写"林夙"全名 + 拒绝代签，但林夙没有回应。
- ch3：药放门槛 + 留验，关系推进到"我在观察你的选择"，仍没有两人正面交锋。
- ch4 林窈 + ch5 没回信 + ch6 妹妹护信 + ch7 林崇称量：ch4-ch7 出现明显断档。
- ch8 苏挽隔窗观察赤渊"认"林夙，但没有与林夙产生动作交换。
- ch9-ch10 切到林彻 / 赤渊观察林夙，CP 关系继续让位给外部视角。

> 关系节奏 = "ch1-ch3 有升温，ch4-ch7 空置，ch8-ch10 由 CP 关系转成外部人物观察"。

## 2. 关系动作是否只发生在心里

有效落地的关系动作集中在 ch1-ch3（撕婚书 / 改名 / 送药 / 拒绝代签）。ch4 之后物件大量出现，但都承担了本该由林夙回应的情感动作：

- 药被送了，但没明确被收。
- 信被送了，但没回信。
- 名字被写了，但没被对方当面接住。

苏挽反复解释自己为什么记住名字、为什么不替他签、为什么留下药；林夙几乎没有对苏挽做出针对性的新动作。

## 4. 三个最高 ROI 改稿动作

1. ch2 或 ch3 给林夙一个明确的收或拒（拿进屋不拆 / 退回门外附字 / 留下药碗印 / 让门房传一句"不要再送"）。
2. 把 ch4-ch7 中至少一章改成"主 CP 的后果章"，让关系动作的后果穿过这些章节（ch4 林窈同时发现药入屋 / ch5 "没回"改为派人守后门 / ch6 林夙退回空信封 / ch7 林崇禁林彻去耳房是因林夙已交碎纸）。
3. ch8 远望改成一次不可撤回的微型交锋（让窗 / 让林夙看见自己 / 礼单第九行留字 / 离开前让管事转告"我看见你了"）。

## 5. 跨章重复与入口结论

- 关系动作重复：写名 / 送药 / 藏纸 / 留物反复表达"我不替你决定但我替你留着"，需要一次实际交付或拒收来改变温度。
- 门槛物件重复：ch3 药包与粗瓷碗、ch8 门窗和脚步、ch17 未知物件都把情感放在门外。
- 男性外部视角挤压关系线：ch7 / ch9 / ch10 连续把注意力移到林崇、林彻、赤渊。
- 父子线兑现不足：林崇对林夙的惩罚和保护都间接发生。

## Persona 5 单独结论

- 前 1-3 章的 CP 基础是成立的。
- 林夙对苏挽的有效回应过少。
- ch4-ch7 连续四章几乎没有主 CP 的关系状态变化。
- "信收到但没回"被当作结论使用，没有立即转化为新的关系动作。
- 当前不是"没有 CP"，而是女主主动线清楚，双向关系线尚未形成稳定闭环。
- 不在 L1 模拟里下"读者会追 / 上瘾 / 爆款"的结论；不使用任何机器分数冒充市场排名。
