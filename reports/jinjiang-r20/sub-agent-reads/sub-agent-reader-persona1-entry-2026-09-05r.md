## 一句话盲读后结论（先报）

不是上瘾，但是稳。是 mechanically pass 里偏向"想继续"的那种 mechanically pass。前两章给真人物证钩把人勾住，中段（ch4-ch7）靠回忆 / 内省 / 心理博弈代替物证，血氧下来一次，ch8-ch10 再把血氧顶回正常。整篇没有任何一处"上瘾"级的强刺激（例如章末点题式人物身份彻底翻转、被推上祭坛、合同到期），但 ch1、ch3、ch8 三章是"想点下一章"的真人物证钩，其余七章的章末问题略偏心理总结而非具体未完成事件。

## 每章 0-10 真实阅读感（含点击下一章意愿、卡点、关系/情绪回报、文笔自然度）

### ch1 退婚书

- 综合体感：8.5
- 点下一章意愿：8
- 卡点：几乎没有。开篇 180 字内已经把"漆盒、退婚书、苏家印"全摆上，是干净的压力入场。
- 关系回报：强。林夙撕纸的动作（"这桩婚，不是你们退我。是我退你们。"）+ 指尖压在半枚苏印上这一笔，让关系从"两姓退婚"立刻转成"主动翻桌"。林崇用"耳房药减半 / 北院月钱停"做惩罚式回应，关系代价落地。
- 情绪回报：苏挽没有替林夙骂，也没有替父亲推，是"碎纸我带回去"和"那点苦香比刚才更清楚"双线回收情绪。好。
- 文笔自然度：高。物证（碗沿水痕、铜钱掉在鞋边、碎纸递过门槛）密度合理。没有"夜很静 / 她很难过"那种情绪替身句。
- 章末具体问题：苏挽要不要把父亲的"你替他签"指令落下去。
- 风险：无可见风险，只在后续需要保持这一章的人物比（苏挽主动 / 林夙主动 / 林崇稳压）。

### ch2 叫对人

- 综合体感：7
- 点下一章意愿：6.5
- 卡点：药物细节（黄芪、陈皮、朱砂）密度过高，连续三段"药粉 / 药包 / 药方"，对中段新读者会形成术语压迫。
- 关系回报：中。苏挽把"三公子"改成"林夙"，是一个可写、可不写、但写出来就改写代价的选择——好。但父亲与管事的对手位没有再升级，"去告诉父亲。我明日亲自交给林夙，但不替谁把名字藏起来"这句是被苏挽"吹了吹墨"落住，动作到位，回收偏轻。
- 情绪回报：偏内收。"我明日亲自交给他"配"我不是外客"连发，情绪曲线有点平——三章之内苏挽两次"我仍要去"，缺一个外部对手位来接情绪。
- 文笔自然度：中。"纸封已经被汗气浸软"是好物，"墨没有研匀，笔尖落下时先拖出一小道淡痕"也是好物，但"那一点没有落完的批注"稍装饰。
- 章末具体问题（按）："林夙在哪儿？"——下一章门房如何回应。
- 风险：苏挽的"主动"被"内省"稀释；如果 ch3 不把场面从书桌移到现场，POV 会偏软。

### ch3 三年一碗

- 综合体感：8
- 点下一章意愿：8
- 卡点：林夙喝粥一段节奏稍慢，但被"她没有拆穿林窈"和"药包丢在雪上 / 被挪进屋里"两个动作救回来。
- 关系回报：强。林窈送粥三年 / "我只是顺路"是设定与心疼并行的写法，"以后是我来给你送"一句把姐弟关系翻转。药包从袖中取出、被人挪进屋里半寸，是极少见的"被动也在场"的物证钩。
- 情绪回报：苏挽的"主动"在这一章重新落地——她把药包放到门槛左侧，并退回墙边。"我也听到了门内的话"作为情节收益付给她，没有白跑。
- 文笔自然度：高。"耳房在西角，门房在东边。中间隔着半个后院，连风都不是同一个方向"是少见的物境证据。
- 章末具体问题：1) 林夙的大比是否真能在三个月内兑现；2) 文书右下角空白还在，苏挽要不要把它带回去。
- 风险：林夙"这一世"三个字属于记忆/重生的提示，目前没有交代，读者会被绊。如果系统想藏这一手，ch3-ch5 里不要让林夙再主动说出第二句类似的字。

### ch4 林窈井边

- 综合体感：7
- 点下一章意愿：7
- 卡点：中段井边洗衣物件过熟（搓衣板 / 井沿 / 槐树叶），林窈和林叙的对手戏偏喃喃，没有外部对峙把张力顶上去。
- 关系回报：中等偏强。靛色线头是这一章真正的物证钩。值得指出的是，POV 切换到林窈不是崩坏，是有意的——它给"林夙的秘密不是只发生在林家"提供了一个独立信源。这个设计值得后文接住。
- 情绪回报：中。林窈"我什么都不知道 / 我只是猜"的两连感叹，是身份掩饰，也是一层保护色，但读者看不到她的代价底牌，情绪曲线偏平。
- 文笔自然度：中高。"靛色线头被水泡得发亮"是好物，"做鞋的人不想让人看见它"是少见的"物体意志"的写法。
- 章末具体问题：林窈把线头交给谁。
- 风险：林窈 POV 与苏挽 POV 平行存在时，前 10 章的视角锚定被稀释；这是项目级选择，不在这一章里修。

### ch5 两清

- 综合体感：7
- 点下一章意愿：7
- 卡点："退婚，另议"便笺出现太快，没被苏挽先验真伪，让"两清"二字落得太顺。
- 关系回报：中等。苏挽"两清"草稿写了三遍，最后一版署名留在纸外、收件人署"林夙收"，是两个少见的"我写我责任"动作，对女频古言来说这是好招。
- 情绪回报：被道具压了一点。"墨线太重，纸背立刻透出一条黑痕"是好物，"她没有把废稿揉掉"是情绪动作，但章内没有外部对峙，情绪回收偏内。
- 文笔自然度：中高。"墨线太重，纸背立刻透出一条黑痕。她没有换纸"这一句值得单拎出来，是女频古言里少见的"不擦即承认"。
- 章末具体问题：苏挽看到的茶底那个字究竟是什么。
- 风险：如果"茶底墨锋"在 ch6 之前不被具象化，会变成悬空钩。

### ch6 苏漪夜坐

- 综合体感：7.5
- 点下一章意愿：7.5
- 卡点：苏漪夜坐的 POV 与苏挽的非同步线并行，读者需要多维别针才能跟上，但作者用门槛那道墨痕做了时间抓手，找得回。
- 关系回报：强。"姐姐说没有" / "苏漪说没有写，不是没有寄"——这是少见的"妹妹替姐姐藏秘密"结构，关系代价与身份代价并行。苏漪的手指擦净了墨却决定继续说没有，是一章内两个不同的"没有"。
- 情绪回报：偏紧。纸片烧到"林"字前收回，是这一章的真正钉子。"林"字被救回来这件事比"林夙收"三个字更重。
- 文笔自然度：高。"灯芯往右偏了一下，油盏里的火苗贴着灯壁"是好物。
- 章末具体问题：明早父亲会在书房里看苏漪的哪只手。
- 风险：苏漪 POV 的走向如果长期独占"姐姐的秘密"，会抢苏挽主场；ch8 已经切换回主 POV，结构上算可承受。

### ch7 林崇称量

- 综合体感：8
- 点下一章意愿：7.5
- 卡点：林崇那一段心理总结偏长，对林崇熟悉的女频读者还能进去，对纯新读者容易迷。
- 关系回报：强。林崇把秤砣拨到一半不让"替谁遮掩"这件事变成可见动作，是林家内部第一次看见的"父亲既不让谁说话，也不让谁闭口"。林彻那段"儿子不敢 / 是，父亲"是少见的父子身份翻转。
- 情绪回报：靠物证撑。门槛上那块新磨出的青痕、指腹沾的蓝灰是接 ch4 靛色线头的好钩，是 ch4-ch7 唯一一次外证落地。
- 文笔自然度：中。"秤用了二十年，铜盘被手指磨得发亮"是好物，"新刻度压在旧刻度上，没有把旧的擦掉"是这一章最值钱的隐喻，承担了林崇的位置。
- 章末具体问题：苏挽手里的"林夙收"文书会不会被林崇当面拆开。
- 风险：ch7 偏内、偏总，是一个"称完没结论"的章节；如果 ch8 不立刻把场景推到具体物上，会出现"环境戏"。

### ch8 一眼

- 综合体感：9
- 点下一章意愿：9
- 卡点：几乎没有。冷茶灰 + 第七行陈皮 + 收货票深褐药粉 + 第九行被打断，三个物件在 1800 字内依次铺开，是开书以来物证最密集的一次。
- 关系回报：强。苏挽"今年陈皮若已入库，票上不会只写一个年份"是一句把林家"账面 / 库房"两套账拆开的人物宣言；赤渊的"有意思"在长廊另一端被苏挽读成"称过的稳"，两人第一次以间接目光接住对方。
- 情绪回报：心理与物证配比恰当。"她看见的不是看——是认"是好的章末总结句，但她后面还有把窗推回去、把笔拿起来两个具体动作，回收没有停在虚处。
- 文笔自然度：高。"一股是去年的陈皮 / 一个深褐药粉 / 一个半扇窗"三个层级都走物不走向语气，是这一章能稳在 9 的原因。
- 章末具体问题：茶底沉着一粒丸药，苏挽把它拈走了。
- 风险：丸药进入苏挽袖中，必须在 ch9 或 ch10 由林彻周平线回收，目前 ch9 已经回收一次，但赤渊 POV 那条线还不知道丸药的事，存在跨 POV 暗线风险。

### ch9 林彻磨局

- 综合体感：8
- 点下一章意愿：7.5
- 卡点：磨局三天的节奏靠"记忆里说"承担，读起来有点像旁白。但被"耳房新纸 / 堂屋新座 / 靛色鞋底"三件事的并行调查结构救回来。
- 关系回报：强。林彻按印（不可逆）+ "查不到就把没查到的地方写清楚"是少见的"不替父亲、也不替自己"的中间动作。"三弟今天坐那张椅子的姿势，是接了父亲的事的坐法"是兄弟关系身份翻转。
- 情绪回报：克制但好。"他写的是'认'"和把那张纸揉了扔进废纸篓——情绪出口在动作上，不在语气上。
- 文笔自然度：中高。"靛色线头这种靛是外面买的靛"叠用法是物证式排比，承担了"林夙鞋底不是林家发的"这一核心新信息。
- 章末具体问题：丸药从哪家药铺来。
- 风险：与 ch8 末同构的"认"问题如果继续在 ch10 再问一遍，会形成三连同义钩。

### ch10 赤渊茶凉

- 综合体感：7
- 点下一章意愿：6.5
- 卡点：心理密度再次抬高，对纯新读者门槛上升。"四个'踩门槛'声"的总结偏解说，叠用三次让读者短暂出戏。
- 关系回报：中等。赤渊和余长生这条时间线第一次摆到台面上，作为"赤渊为什么看林夙"的远因，是好招，但章内没有让这条时间线落地——木匣没打开，遗记没展开。
- 情绪回报：偏静。"他决定不立刻回宗门。他要在城东再住一个月"是一句不张扬的人物选择，但相对 ch8-ch9 的血脉张力，回落明显。
- 文笔自然度：中高。"他接的是那个砣的稳——不是砣的数，是砣的稳"是好物，但同章内"他知道 / 他只把这件事在心里过了一遍"这一类"他"起句出现过多，读感上像论文。
- 章末具体问题：木匣锁扣会不会被打开。
- 风险：ch10 的张力低于 ch8 / ch9；从追读体感上是"血氧下来"，但 ch11 接住仍是自然连续。

## 三句原文证据（含章节、原文、它证明了什么）

1. ch1：原文「林夙把剩下的纸又撕了一次…这桩婚，不是你们退我。是我退你们。」
   证明：第二章的关系代价（退婚）不是被退，而是人物主动选择翻桌。这是一章里唯一一次把"代价"变成"主动"的位置，是给苏挽之后敢动手的合法性背书。
2. ch8：原文「票角有一道新折痕，折痕里沾着深褐色的药粉，不像刚从库房取出来的。她用指腹碰了一下，没有抖掉。」
   证明：物证链在不开上帝视角的前提下完成"她看见了什么"。这章没有用一句心理总结替代动作，是前 10 章文笔最克制、密度最高的一章，所以阅读体感 9。
3. ch3：原文「她把药包放到门槛左侧…再看门槛，药包比她来时短了一寸。它被人挪进了屋里。」
   证明：苏挽的"主动"不只是行动，而是主动观察"动作是否被对方接走"。这一章确立了"女主送物不逼人收"的写法。

## 整体判断（不冒充真人，只给 L1 体感）

- 这是 mechanically pass，不是上瘾，不是好看。
- "想点下一章"的吸引力集中在 ch1、ch3、ch8 三章，其余七章处于"想继续但不是非要看"的中段。
- 关系 / 情绪回报在 ch1、ch4、ch6、ch8、ch9 这五章做足，但在 ch5、ch7、ch10 三章偏内收。
- 文笔自然度整体在 7-9 之间，没出现真正破坏沉浸的代笔语气，也没有出现"明日再看 / 夜很静"那种情绪替身。
- 章末具体未完成事件：ch1（是否替他签）/ ch3（药包被谁挪走）/ ch4（线头交给谁）/ ch5（茶底墨锋是哪一个字）/ ch6（明早父亲看哪只手）/ ch7（林崇会不会拆开文书）/ ch8（茶底丸药）/ ch9（丸药从哪家药铺来）/ ch10（木匣锁扣会不会被打开）。其中只有 ch4、ch5 还没有落地物，需在 ch11-ch12 接住。

## 给项目工作流的最小可执行建议（不改文件）

- 把 ch5 章末的"茶底墨锋"在 ch6 或 ch7 由苏挽直接说出来（说一个字、点一个字都行），不要让它超过两章不兑现，否则它会沦为项目工程上的"未挂章末"。
- 把 ch10 章末的"木匣锁扣"压缩到一句（林崇或赤渊的一指按下去），少一次心理总结，让 ch10 的章末物证密度不低于 ch8。
- 在 ch7 已经摆出"门槛青痕 + 蓝灰"的好物证后，ch8 / ch9 之间应补一次外证复核（例如林窈或牛阿大在路上再见靛色鞋底），否则单靠林彻一人的判断，证据会显得太干净。
