## 1. 独立可读性：看不懂的术语和人名

盲读完十章，下面这些点和人物身份读完之后仍然粘滞。

- 宗族与衙门不分。林家有“议事堂”“管事”“姨娘”“大公子”“三公子”，按常识是大户人家自己管族内事，可是又出来“宗门”“大比”“赤渊长老”“内门”“外门”“淬体一重”。分不清“宗门”是官府、是书院、是武林门派、还是某种国中之国的统治机构。“林家在宗门里说得上话的人只有城东那位养病的赤渊长老”，这意味着宗门和林家有上下级关系，那又跟“退婚是亲族礼单”的民商逻辑对不上。
- “耳房”到底在哪个行政级别。第三章“门房小厮从东边绕过来”、第七章林崇说“别让你的人去耳房”、第十章赤渊让人打听“东跨院最末一间，朝北，没有火炕”，这像是族内私宅的某个偏院，但又不是一般的“下人房”。读完后只勉强知道：耳房是林家把不被承认的子弟“扔”进去的冷屋子，至于它是罚、是弃、还是某种保存，全靠用“前情提要”脑补。
- 人物名字与人称。前两章出来的人：林夙、林彻、林崇、林窈、林叙、苏挽、苏漪、苏父、林家管事、苏家管事、丫鬟云栀、牛阿大。盲读时经常把“林叙”和“林崇”搞混，因为都是林家长辈辈分的名字；“林窈”和“林夙”字形也很近，开头两章全靠“小姑娘抱碗”“少年跪在青砖上”撑住。第一章没有给任何角色生卒介绍，到第八章才知道林彻是林崇的儿子、是林夙的哥哥（大哥）。
- “赤渊”是人名还是封号。第一次出现是“城东那位养病的赤渊长老”，到第十章直接进他视角，才确认这是人。可前九章读者只能从旁人的称呼里去猜“赤渊”是个什么样的人，到底是林家的客卿、宗门钦差，还是族内供养的高人。

> 对一个非仙侠读者来说，独立可读性勉强及格：物件驱动写得很扎实（药包、碎纸、铜钱、秤、冷茶、青砖上的靛色脚印），场景几乎都能想象，但术语这层“宗门 / 大比 / 内门外门 / 淬体一重”是几乎不解释的，对新读者非常不友好。

## 2. 主角当下痛点和下一步必须做什么

假装自己追到了第十回，整理一下每个 POV 角色在这一章结束时的状态：

- ch1 苏挽：当堂看着林夙撕碎退婚书，父亲命令她“明日替林夙落名”，她拒绝。结尾她攥着纸角和药香，“明日，她还要再去一次”。痛点清楚：她是苏家派来办事的女儿，却不肯替别人把名字藏起来。下一步读者预期是：她去林家，会把名字怎么交、怎么处理父亲的命令。
- ch2 苏挽：在文书上亲手把“林三公子”划掉、改写成“林夙”，但没有盖印、没有送出。结尾“林夙在哪儿？”。痛点仍在升级。下一步预期：她拿着这份文书去林家后门找人。
- ch3 苏挽（+ 少量林夙门内对话）：她把药包放到耳房门槛外，听到林夙跟林窈说“三个月后宗门大比……淬体一重的废名底下，藏着另一条路”。结尾她上车，膝上是药包、袖中是文书，“你把哪一世，带回来了？”，痛点清楚。下一步预期：她要当面问林夙“这一世”是什么意思。
- ch4 林窈：独立章。发现三哥鞋底藏着靛色线头、林家布坊不出这种颜色。结尾她把线头包进旧布塞到衣襟里，“如果把它交给大哥，明天整个林家都会知道”。痛点清楚：她手里捏着可能让三哥“暴露”的证据，不知道该交给谁。下一步预期：她会先压住，还是会跟谁摊牌。
- ch5 苏挽：写“两清”信，不署苏家名，只署“林夙收”。三日后回报：林家“信收到了”，林夙没回；林彻摔了茶盏。结尾她发现砚台底下那张旧信“边角露出的墨锋不是‘林’，是一个她没在苏家见过、却在今日那盏茶底瞥见过一次的字”。这里痛点突变：本来以为是退婚线的延伸，结尾突然插入“另一个字”的钩子。下一步预期：她要查那个字。
- ch6 苏漪（独立章）：捡到姐姐文书的碎纸“林夙收”，差点烧掉又灭下来，对管事说“她没写”。结尾她盯着手指上的墨，准备明早面对父亲。痛点清楚：她在替姐姐顶一句谎，赌父亲听不出“没写 ≠ 没寄”的差别。下一步预期：明早书房过堂。
- ch7 林崇：用那杆旧秤当面对林彻“称”了一把，告诉他“别让你的人去耳房”。结尾听说苏挽又到后门、文书收件人写“林夙”，他“忽然不急着叫三儿了”，让管事把苏挽请进来。痛点清楚：林崇本来要敲打林彻，听说苏挽用“林夙”做收件人，态度立即松动了。下一步预期：苏挽 vs 林崇在堂屋对一次话。
- ch8 苏挽：去林家对账陈皮数目，隔窗目睹赤渊看林夙那一眼（“不是打量，不是威胁，是另一种东西”）。结尾她把茶底沉着的丸药拈出来放进袖中。痛点清楚了，但丸药这根线是新的。下一步预期：丸药是什么，谁放的，跟赤渊、林彻谁有关。
- ch9 林彻（独立章）：终于给他完整 POV。他在紫檀大案后“磨了三天”，第一件事磨人、第二件事磨话、第三件事磨自己，结尾写下一个“认”字又揉掉。痛点清楚：他在父亲的秤、林夙的椅子、赤渊的“认”这三件事里看到了“自己被算进去”。下一步预期：他要动手查耳房新纸、堂屋新座、靛色鞋底这三件事。
- ch10 赤渊：独立章，回城东院子。决定“再住一个月”，不让打开那份六十年前的遗记原本，要先打听林夙这三年的衣裳鞋袜是谁发的。结尾“林家三公子身上，究竟是谁的东西？”痛点清楚：他已经动了心，但要等证据才肯开匣。下一步预期：他拿到“衣裳鞋袜”的回报后才会动匣子。

整体评估：十章里每章结尾都给一个“下一章必须回答”的具体问题（不是“夜很静”），这一点做得不错。痛点也清楚。扣分项是 ch5 末尾突然出现的“那盏茶底瞥见过一次的字”，这个钩子前面九章从来没有在任何地方看见铺垫过，作为新读者读到时以为自己在读第二本书。

## 3. 视角混淆

盲读完一遍后，反复核了一下视角切换：

- POV 切换清晰的部分：ch1/ch2/ch3/ch5 都是苏挽；ch4 林窈；ch6 苏漪；ch7 林崇；ch8 苏挽；ch9 林彻；ch10 赤渊。每一章只切一次（除 ch3 末尾偷听林夙门内对话，那段是用苏挽耳闻的方式写，不是真切进林夙视角，这一点处理得不错）。
- 轻微混淆 1：ch5 末段“她把砚台往前挪了一寸，压住两张纸的边角。窗外有人挑着馄饨担子经过……”这个动作和上一句几乎一模一样，正文里连续出现两次（“她把砚台往前挪了一寸，压住两张纸的边角”重复了一遍）。读者会怀疑是不是排版错了，但前文完全没出错，这让人对作者产生“是不是故意”的怀疑，对一个不熟悉的作者来说会扣信任。
- 轻微混淆 2：ch8 末段“那盏冷茶还搁在条案上”也连续出现了两次，紧接着才是丸药。结构上和 ch5 同一处瑕疵。
- ch10 视角最稳：进入赤渊之后节奏反而最清楚，每一段都有“他做了什么、想什么、为什么停下”的内在逻辑，几乎是这十章里最像“晋江男主新登场”的章节。
- ch9 林彻的“算”和“磨”比较抽象，但还在可理解范围。他磨人、磨话、磨自己三层逻辑清楚；只是和父亲那杆秤的对位，“铁砣压在木砣上”这种意象对一个新读者需要回看一次才能反应过来。

整体判断：视角不混淆，但有两处明显重复句（ch5 末、ch8 末）让人怀疑是工程事故而不是修辞。

## 4. 三个最高 ROI 改稿动作

作为跨题材新读者，最影响“会不会点下一章”的不是“文笔再润色”，而是下面三件事。这三件事改了，前 20% 的入口才会真的立起来：

1. 第一章加 3 行“世界坐标”。在前 200 字里，至少要让读者明白：(a) 林家 vs 苏家是什么关系（联姻世家？门阀？），(b) “宗门”是什么机构（朝廷的修仙部门？独立门派？管什么？），(c) “大比”对林家意味着什么（为什么林彻要在考前跑去城东拜赤渊）。现在第一章读完之后还以为这是民国/古装宅斗，到第八章才发现是仙侠。这三行不需要长，可以嵌在父亲或林崇的台词里，例如父亲交代苏挽时顺嘴说“宗门大比三年一次，林家若再没有人进前十……”。ROI 极高：让新读者第一回就定位题材和赌注。
2. 修掉 ch5 末、ch8 末的重复句，并把 ch5 那个“她没在苏家见过、却在今日那盏茶底瞥见过一次的字”这一钩子在 ch1–ch4 至少铺一次。ch5 这个钩子现在的代价是读者到 ch9/ch10 才发现是 ch10 的“余长生遗记原本”，中间四章完全断线。哪怕只在 ch3 林窈端碗那段，让她瞥一眼碗底压着的纸角，印出半个字（不必让读者认出），就能接住这条线。ROI 高：把全书的“赤渊 / 余长生 / 遗记”暗线从第八章才浮出，提前到第三章就埋。
3. 第一章末或第二章初让苏挽在“奉命退婚”和“称他名字”之间有一次可见代价。现在苏挽在 ch2 末把“林夙”两个字写上纸面，是非常重要的选择，但代价只是父亲可能会生气，这对晋江古言读者来说太轻了。最少要做到以下任一件：(a) 父亲明确威胁苏挽“你若不落名，下一桩苏家的婚事也不会由你说了算”，让她在退掉林家的同时也失去自己未来的选择权；(b) 让她亲手把父亲给的那枚苏家小印交还或按下印面（一个不可逆动作），在 ch2 末做出。这是把“女强女谋读者会追更”的最大动作，目前苏挽的反抗全停在语言层。ROI 高：把苏挽的主动性从“敢写名字”升级为“敢把自己也搭进去”。

## 对晋江 L2 真读者的诚实保留

以上全是 L1 模拟判断，不能等同真人读者会追。晋江古言仙侠资深读者很可能反过来把 ch10 的“认”视作整本书最值钱的一笔；而追更党很可能觉得 ch7 林崇的秤戏太静态。没有真人样本，下结论只到 L1。
