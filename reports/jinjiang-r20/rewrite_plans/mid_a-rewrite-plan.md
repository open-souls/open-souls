## 2. 候选改稿单元（按 R1–R5 + E1–E5 双轨预审）

### 2.1 ch504（按 reader-2.json）

- **当前问题**：首句静态，三行无动作；首段无人物 + 无阻力。
- **改稿方向**（如触发）：
  - 首段必须出现动作 + 阻力（E1）：把第一句改成 POV 角色与人物之间的一次实物交接（"她把那张纸按在膝上。没按平"）。
  - 中段加一次 POV 主动选择（E2 / R4）：让 POV 角色在 504 中段必须决定"按 / 不按"或"递 / 不递"。
  - 章尾给下一章必答的具体问题（R2）：末句落在"门外有人在问这张纸是谁的"。

### 2.2 ch505（按 reader-2.json + reader-1-真人 候选降级版）

- **当前问题**：F 式对话滥用（"嗯。"/"在。"）压住推进；正文最后落到"她没回"。
- **改稿方向**（如触发）：
  - F 式对话只保留 ≥3 处作为风格锚点；其余替换为有潜台词的台词或动作（参 `文笔范文标准.md §二` 范文 G）。
  - 中段补一次可见选择 + 代价（E2 / R4）：POV 角色必须做一次"签下 / 退掉"的真实动作，且后段必须承接其后果。
  - 章尾必须落在动作前 1 寸或新证据（R2 / R3）：禁止"她没回""明日再看"作为收尾。

### 2.3 ch506（按 reader-1-真人.json 候选降级版）

- **当前问题**：同一物证反复释义，局势没有前进。
- **改稿方向**（如触发）：
  - 物证要么进仓库（被换掉 / 被烧 / 被收起），要么被替换成一个**新**物证（"那张纸被换成了一截线头"）。任选其一，避免反复释义。
  - 中段必须有一次关系后果兑现（E5 / R3）：让至少一对有名有姓在场人物的关系发生升降（信任 / 亏欠 / 秘密兑现）。
  - 章末必须落在身份误认或新证据（R2 / R3）：禁止"屋内安静"型气氛收尾。
