## 0. 三句话

1. **晋江爆款没有官方定义**。"爆款"是创作者社区口语，可被 cite 的下限是
   晋江站内的签约 / 入 V / 营养液 / 霸王票数字。任何"读者会追 / 爆款 / 上瘾"
   措辞在 L2 = 0 期间仍然被禁止。
2. **可工程化的指标是有限的**。工程 5 维 + lint 6 道墙可以代理"是不是写崩了"，
   但收藏 / 营养液 / 追更 / 完结率 / 编辑判断是平台私有数据，本季 0 接入。
3. **5 读者交叉的真实价值不在 5 个判断**，在 5 份中**重复出现的具体章号 / 具体物 /
   具体动作**——这是升级为结构性改稿任务的硬证据。Sub-agent A 已经报出
   "蜡信压在棋盒盖上，叶观澜拈起，没拆" 是 `mid_a` 包的最强钩；

### 4.2 5 工艺红旗的 lint 实现优先级（研究端建议，主编审批后施工）

| 规则 ID | 触发 | 输出 | 落地 |
|---|---|---|---|
| **JJ-LINT-01 那一 X** | `len(re.findall(r"那一[一-鿿]{1,3}", body))` ≥ 6 → WARN，≥ 10 → ERROR | "「那一 X」物象位置回环 N 次（阈 6 WARN / 10 ERROR）；删整句，不换同义词" | 现 `engine/prose_lint.py` 的 MOTIF_SLOT 阈 30 偏高；抽样 1076=18 即漏报 |
| **JJ-LINT-02 自己** | `body.count("自己") >= 行数 / 4` → WARN（≥ 1/2 → ERROR） | "「自己」回环 N 次 / 行数 M（占比 X%），把动作主语换成具名角色" | 现 `engine/prose_lint.py` 的 SELF_CLAIM 只匹配"我/他/她自己"，纯"自己"没独立计 |
| **JJ-LINT-03 末段短句密度** | 末 6 行 ≥ 4 行 ≤ 6 字且无具体动作 → WARN | "章末 N 行短句（≤ 6 字）无动作落地，合并或补一个具体动作" | 无 |
| **JJ-LINT-04 POV 远观** | 同章 ≥ 5 个有名角色 ≥ 80% 描写仅手 / 袖 / 背影 → WARN | "POV 远观 N 个角色只见手 / 袖 / 背影，拆 POV 进入单人近景" | 无 |
| **JJ-LINT-05 问答空转** | `len(re.findall(r"「", body)) >= 8` 且 agency < 2 → ERROR | "问答循环 N 段 + agency verb < 2：在循环里插 ≥ 1 个动作兑现" | 无。

外加两条配套 WARN（与 M3 工艺直接冲突）：

| 规则 ID | 触发 | 输出 |
|---|---|---|
| **JJ-LINT-06 末段气氛句** | 末 3 行内任意一行匹配 `(屋里|夜|风|雪|火|雨|街上).*(很静|没?停|没?熄|没?响)` | "章末气氛句「…」替代了具体动作（M3 禁用 5），换成动作 / 问题 / 新证据" |
| **JJ-LINT-07 单字断章** | 末行匹配 `^[一-鿿]{1,2}[。！？…」』]$` | "章末单字断章（M3 禁用）；至少扩到「她/他 + 一个未完成动作」" |

### 4.3 与现有 lint 的不冲突保证

- 现有 6 道墙针对**公式句 / 模板回环**。
- 新增 JJ-LINT-01–07 针对**晋江读者最敏感的「气氛收尾 + 低烈度物象回环 + POV 让位 + 问答空转」**。
- 与 `docs/standards/jinjiang-edit-modes.md` 的对应：JJ-LINT-01/02 = 工艺 5 条 1/2；JJ-LINT-03 = 工艺 5 条 3；JJ-LINT-04 = 工艺 5 条 4；JJ-LINT-05 = 工艺 5 条 5。
- 与 `tools/review_batch.py --strict-editorial` 的接驳：每条 ERROR → 该章必须结构性重写；每条 WARN → 重写一段才准 commit。

## 6. 不能由代码证明的市场结果（硬边界）

| 维度 | 不能代码证明的原因 |
|---|---|
| 晋江站内收藏数 | 平台私有数据，无 API |

| "上瘾" | 心理学构念，无单一指标 |
