## 2. 今晚改稿顺序（≥3 persona 同点）

### 优先级 1 · ch3 章尾补"药包被谁拿走"

- 五个 persona 同点全部命中（4 个直接 + Persona 1 conditional）。
- 现状：女主主动占比跌到 38%，药包落门槛没写到"拿 / 收 / 拒 / 退"。
- 最低改法（任选一笔）：
  - 在 ch3 倒数第三段"她要看他会不会拿走这包药"之前，加一句"门内那盏灯的火苗晃了一下，药包的影子比她来时长了一寸"或"药包比她来时短了一寸"。
  - 让小厮回一句"林公子把药包挪到窗台上"（POV 不破）。
  - 让林窈在夜色前回门槛把药包取走（POV 切走但合规）。

### 优先级 2 · ch5 章尾"茶底字"必须被一个动作承接

- 四个 persona 同点命中。
- 现状：ch1-4 没有铺"茶底字"对应物，ch5 章末读者会以为自己在读另一本书。
- 最低改法：在 ch5 章末补一段苏挽动作，"她从砚台底下把那张旧信抽出来，把那个墨锋对着灯火照了一遍，又压回去，在第二张废纸上画了一笔，不是字，是那个墨锋的形状。"同时删掉一次"她重新翻开药经"的重复段（prose_lint JJ-LINT-02 自己回环也要求）。

### 优先级 3 · ch7 或 ch9 章尾补 80-120 字苏挽侧动作

- 三个 persona 把 ch7/ch9/ch10 标成"女主连续缺席"的结构性风险。
- 现状：女主在 ch7 / ch9 / ch10 连续三章只在 ch8 出现一次，占比 40%。
- 最低改法：在 ch9 章尾之后、ch10 标题之前补一节 ~100 字"苏挽回苏家，把丸药切半 / 把砚台底旧信的墨锋对着灯照了三次"。
- 这笔 ROI 高，因为它一次解决 Persona 4 的"女主缺席"和 Persona 2 的"丸药/茶底字双兑现"。

### 优先级 4 · ch8 章末"丸药"必须立刻承接

- 四个 persona 同点命中；这是 Persona 2 / Persona 4 都明确指出的窗口最关键留置物。
- 现状：ch8 末丸药拈出来放袖中，ch9/ch10 都没回到丸药。
- 最低改法：在 ch10 章末让赤渊主动提到"城东堂口今天有人把一味丸药换成新的"，让丸药进入宗门一侧的视线；或让 ch9 章尾苏挽切半丸药时直接把那半颗交给周平。

### 优先级 5 · ch4 林窈私线 → 与 ch3 药包挂钩

- Persona 4 / Persona 5 都觉得 ch4 是窗口掉速章；但 Persona 3 / Persona 5 觉得 ch4 的痛点清楚。
- 最低改法：在 ch4 林窈挑线时，让她同时发现耳房门内收进了 ch3 的药包，把"挑线"和"送药"两件事并到一次发现，让 ch4 不再是孤立的次级线。

## 4. 不允许写进文档的措辞

- "读者会追" / "上瘾" / "爆款" / "已经到 Top 20%" / "对标晋江头部" / "碾压同档" / "头部地位"
- 真人 L2 = 0 时，工程分不能被改写成读者分。
- 任何把单次读者模拟当多人聚合结论的句子。

## 5. 失败兜底

- 如果任何一笔改稿让 E1-E5 任意一维 ≤ 6：回滚，不留 forward 痕迹。
- 如果五读者 diversity_score 跌到 < 0.5：暂停当轮改稿，重跑 verify。
- 如果任何"留置物"被改成"被解释掉"，而不是被一个动作承接：当作新风险上报，不计入有效改稿。

## 6. 与今晚冲刺的诚实边界

- 我们今晚能保证的：把 ch3 / ch5 / ch8 / ch9 / ch10 的"留置物"与"女主缺席"两类结构风险落到笔下，并跑通工程门禁（lint / audit / rubric / panel）。
- 我们今晚**不能保证**的：晋江排名、读者留存率、平台收藏、营养液、霸王票、真人 L2 反馈。L2 = 0 的边界今天仍未改变。
- 离晋江 Top 20% 最近的三项差距（不夸大）：
     - 女主弧线在 ch4-ch7 / ch9-ch10 连续缺席；
     - 留置物（ch3 药包 / ch5 茶底字 / ch8 丸药）兑现率低；
     - 世界坐标（宗门 / 大比 / 内门外门）从未在前 200 字明说，新读者入题材成本高。
- 后续必须真人 L2 ≥ 1 才能把这三项升级为"已修"，否则一律保留为"待验证"。
## 7. 本轮实际落地与延期

本轮只落了三类高置信正文修复：

- `ch3`：苏挽观察到药包被挪进屋内，把“会不会拿走”变成可验证的收取回执。
- `ch5`：删除重复尾段，苏挽把茶底字的墨锋描到第二张废纸上，证据进入下一步动作。
- `ch8`：删除重复的冷茶观察段，保留丸药的唯一物理承接。

两项建议暂缓：

- `ch4` 不接药包。正文时间顺序不足以证明林窈在 ch3 之后才发现药包，硬接会制造连续性错误。
- `ch9` 不跨 POV 插入苏挽尾段。林彻章内强行切苏挽会破坏视角协议，需等下一章有自然承接点再改。

因此本轮不是“所有建议都执行”，而是以连续性优先筛掉两笔风险改稿。下一轮先复测 `ch3/ch5/ch8` 的 E1 至 E6、lint、audit 与跨章承接，再决定是否把丸药送入 `ch9` 或 `ch10`。
