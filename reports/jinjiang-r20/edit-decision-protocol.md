# 编辑判断协议

配合 `jinjiang-rubric.md` 使用。本协议只回答“该不该改”，不代替作者完成改写。

## 0. 一句话规则

写之前先答：本章谁要什么，谁阻止，付出什么代价？

如果答不上来，先补背景；如果代价是空，本章就该删或重构。

## 1. 写作前五问

1. POV 角色是谁？本章核心欲是什么？
2. 谁挡在中间？是人、证据还是时间？
3. 阻力具体到什么程度？读者能否复述？
4. POV 角色最后做了什么动作或决定？
5. 章尾读者必须问的下个问题是什么？

答不出第五问，重写末段。

## 2. 写作后五问

1. 首段是否出现动作与阻力，而不是先写景？
2. 中段是否至少有一次 POV 角色的选择？
3. 章尾是否停在动作前、新证据或未答问题？
4. 关系或信息是否真的改变？没有就重写。
5. 是否删除同义重复句，而不是只换词？

## 3. 改稿顺序

先处理五读者交叉中达到至少 3 个 persona 同点的入口结构风险，再处理单 persona 的文风偏好。2026-09-05 第二轮 L1 模拟把顺序锁为：

1. `ch3` 章尾补“药包被谁拿走”的可见承接，避免送出物件无收、POV 只观察。
2. `ch5` 删除重复段，并让苏挽对“茶底字”再做一个证据动作，避免新证据只停在解释。
3. `ch9` 章尾补 80 至 120 字苏挽侧动作，拉回 `ch7` 至 `ch10` 连续男方视角造成的女主缺席。
4. 让 `ch8` 丸药在 `ch9` 或 `ch10` 进入某个角色的明确选择，不新增无法兑现的谜面。
5. 让 `ch4` 林窈私线看见 `ch3` 药包的收取或拒收结果，把副线与主线物件接上。
6. 再评估是否需要在 `ch1` 前 200 字补三行世界坐标，优先用既有对白，不另起说明段。
7. 让 `ch10` 的身份钩在下一章转成一次林夙与相关人物的直接关系动作。

每章只允许一个最高价值改动。任何动作必须记录原风险、正文证据、下一章兑现责任和反证条件；禁止为降低 `JJ-LINT-01` 而删掉有效戏。五读者模拟是 L1 工艺证据，不是真人反馈；L2 = 0 时不得升级为市场结论。

### 3.2 P1 钩子债的近期兑现责任

下列债务在下一次相关大事件中必须产生“压力、选择、代价、状态变化、下一压力”闭环。具体关账动作必须先落到 `reports/jinjiang-r20/redemption-ledger/`，再把状态回写至 `reader-debt-v1.md`，不得用新增谜面替代兑现。

- `D-02`：林夙“这一世”。必须说明这句改变了谁的当前选择，而不只补前世解释。
- `D-04`：冷茶底丸药。必须追到来源、服用者或物证流向之一。
- `D-05`：沈疏桐悬赏令。必须让苏挽知情并进入处置链，而不只由林夙救人。
- `D-14`：密闭空间药味。必须把药方指向一个可行动的具体人或地点。
- `D-17`：阿湄带名字的消息。必须在 `ch51+` 的短距离内交给能承担后果的人，不能再以“明日”延后。

`D-01`、`D-06`、`D-09`、`D-11`、`D-12`、`D-16` 为 YELLOW 或 RED 的次级债；每次改动相关人物或物件时必须先检查其兑现账，不能再新增同类悬停。

旧的通用顺序仍有效：

1. 短章：补选择、阻力、代价或新信息，不补空景物。
2. 章尾弱：补下章必答的具体问题，不补泛化隐喻。
3. 句子重复：删除整句，不做同义替换。
4. 填充描写：删除整段，不要软化。
5. 开句同构：重做首句结构，不要扰动中段。
6. 编辑标记或公式回环：重写整章，不做局部遮盖。
## 4. 常见借口不通过

- “我已经写了”：重写或重写末段。
- “留给下一章”：本章仍须提供具体钩子。
- “这是文学笔法”：文学笔法也要改变人物、信息或关系。
- “读者会理解”：读者不欠作者理解。
- “工程分是 9.8”：工程分不是市场分。
