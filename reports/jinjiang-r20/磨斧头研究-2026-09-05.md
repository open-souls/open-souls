## 1. 晋江爆款研究端 · 证据分层 (本轮新增的工程层 + 真人层研究)

### 1.1 S0 晋江官方可验证事实

- `help.jjwxc.net` 上对签约、文案、营养液、合规的官方表述不构成"爆款标准",只构成"合法 + 可发布"门槛。
- "爆款"不是晋江官方用语,是创作者社区对"收藏 / 营养液 / 霸王票 / VIP 订阅"高位运行的统称。

### 1.2 S1 行业共识(标为推断)

来源:晋江 BBS 创作者访谈、出版编辑公邮、豆瓣阅读写作手册、知乎专栏(标记为社区共识,**不是晋江官方**)。

- **黄金三章**:前 3 章必须建立主读者承诺、POV 主动决策、关系升压。读者在第 1 章停留 < 50% 占比的章节不能进盲读池。
- **钩子前置**:开篇 180 字内出现 ≥ 2 个动作动词 + 阻力词(却、但、不肯、不能)→ S2 工程代理 E1。
- **信息差**:每章结束必须留读者与角色不同步的具体问题(下一章要回答的)。"她没回"是钩;"她心里很难过"是泛化情绪,不是钩。
- **爽点 / 虐点**:爽点是"付出代价后获得具体回报"(动作 / 物件 / 关系确认);虐点是"主动选择被拒绝后承担身份后果"。两者都要有具体动作,不能靠文笔替代。
- **CP 线升级**:每 5-10 章必须有可观察的关系变化(从远到近 / 从近到远 / 从误会到解 / 从解到隔)。变化必须用物件、对话、动作落地。
- **文笔**:晋江女频档的文笔不是"形容词华丽",而是"露骨比直给更上瘾"(用户 2026-09-04 原话)。具体表现:不解释心理,只用身体、物件、对话。
- **追更心理**:读者追更来自"5 章内必答一个问题"+ "每章末有具体未完成动作"。"明日再看"是低粘性钩,要避免。
