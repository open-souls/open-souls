# 真人读者盲读协议

这是唯一可以宣称“晋江爆款 / 上瘾”的依据。算法分不能替代真人判断。

## 0. 硬原则

- 没有任何真人读者数据时，禁止使用“上瘾”“爆款”“读者会追”等判断。
- 工程审分与真人盲读分必须独立打分，取最低。

## 1. 盲读包结构

三包必备，覆盖不同读者接触点：

- 开篇包：第 1 至 10 回，验证第一卷能否吸住读者。
- 中段包 A：第 501 至 510 回，验证中段关系后果是否兑现。
- 中段包 B：第 681 至 690 回，验证证据线在重压下不崩。
- 最新包：第 1136 至 1145 回，验证追读到现在的动力仍存在。

包内章节顺序随机化，避免读者顺着原顺序读。

## 2. 读者条件

- 不看章节标签、不看 frontmatter、不看 review、不看分。
- 不告诉读者“这是晋江连载”，只说“读完告诉我最想看哪一段”。
- 至少 5 名读者；至少 3 名完全没看过古言仙侠，验证跨题材吸力。
- 至少 3 名愿意读到第 50 章以上，验证中段留人能力。

## 3. 必记录的四项

1. 首弃读章。
2. 最想看的关系，写自由回答，不列选项。
3. 最想看下一章的哪一节。
4. 是否愿意读到 50 章以上，写 yes/no 与 50 字理由。

## 4. 结构性升级

- 三位及以上读者在同一章弃读，该章必须重写。
- 三位及以上读者追问同一段关系，该关系必须有可见动作兑现。
- 三位及以上读者点出“信息没变行动”，记入禁区第七条。
- 三位及以上读者“读到 30 章就停了”，中段包不通过，必须做关系后果清算。

## 5. 生成工具

运行：
```
py -3 -X utf8 tools\reader_blindtest_pack.py
```

生成三包 markdown 与一份索引 csv，仅用于阅读，不修改正文。
